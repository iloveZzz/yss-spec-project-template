# YSS 项目入口

使用简体中文。按用户目标与已有授权直接开展工作，按需读取相关需求、代码及根 CONTEXT.md。

- 优先使用适用的 YSS 技能；后端工程命令优先 ./mvnw，前端优先 pnpm。
- 技能位于 .agents/skills，业务与工程参考位于 .template-spec；宿主技能副本由安装记录管理。
- 不要求生命周期路由、阶段批准、checkpoint、检查计划或测试报告。构建、测试与审查按当前任务需要开展。
- 保留权限、业务输入校验、错误处理与用户文件保护。提交、推送和发布使用对应授权。
- 使用已安装 CLI 的实际帮助。支持本版接口时，sync 更新文件，--dry-run 仅预览；doctor 查看差异，recover 处理未完成文件事务。
- 不覆盖无关工作。交付说明实际改动与未执行事项，不把生成或编译结果当作未执行的测试结果。
