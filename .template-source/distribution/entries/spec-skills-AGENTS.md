# 工程协作入口

使用简体中文。在用户授权的工程和范围内完成任务，复用当前对话、需求及验收。

先使用 `yss-product-lifecycle`（life）路由当前需求：未定规则用 grilling，事实用 yss-research，词汇用 domain-modeling；已确认需求由 life 直接整理普通规格草稿，写作使用 i-have-adhd。`to-spec`、`implement` 仅在用户明确调用时使用，安装不授予隐式调用资格。

按描述选择已安装技能，只读取当前任务需要的代码和参考。普通任务无需生命周期路由、注册、checkpoint、Slice 或 tracker 初始化。专业输入缺失先调查，只询问真实缺失的决定。

实现后运行受影响的实际检查并复核当前 diff，默认真实自检；用户或实际外部要求需要时独立复核。只报告已执行的结果和未覆盖范围，不以文档完整代替验证。

不覆盖用户工作；修改、提交、推送、发布、部署分别遵循当前实际授权，复用仍有效的范围。安装或同步需要时由工具核验来源、路径、冲突和事务。

规格工作围绕目标、规则、验收与已有材料展开；不默认创建 CONTEXT.md、正式 Ticket 或批准。已有治理、正式任务或非法身份不回退普通路径；正式化需显式接入并核验当前合同。按需要补充专业技能，不把默认八项视为所有专项能力。
