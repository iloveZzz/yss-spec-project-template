# YSS Backend 技能入口

Backend 默认预装 41 项研发技能及必要参考资源，可用库共 53 项；实际集合由运行 CLI 的 Bundle 决定。使用简体中文，按用户当前目标和已有授权选择技能，不要求启用治理流程或补建项目文档。

- 已授权研发满足任务可拆、依赖明确、路径及运行资源可隔离且宿主允许时，由 implement 自行并行并负责集成验证；条件不满足则顺序完成。
- 承接 Spec 或明确需求，按需完成拆分、架构/技术/详细设计、脚手架、开发与测试；只读设计不转实现，MVC 不补 DDD 层，普通测试不强制 TDD。
- to-tickets 只细化研发实现切片，读取真实工程与适用设计，不要求先补业务票，不凭模板猜测生产方案。免除流程审批不扩大当前任务范围。
- 完整交付包含构建部署手册，优先更新既有 README/运维说明；部署只编写说明，不执行部署或建设 CI/CD/云资源。
- 技能位于 .agents/skills，宿主副本由安装记录管理；已有项目规则与业务约束继续适用。
- 后端工程命令优先 ./mvnw，前端优先 pnpm。构建、测试和审查按当前任务需要开展，不作为统一前置。
- 保留权限、业务输入校验、错误处理和文件保护；不覆盖无关用户修改，不把子模块当普通目录。
- 使用 CLI 实际帮助中的安装与同步能力；支持本版时用 sync 更新、--dry-run 预览，skills ensure 补装指定技能。
- 提交、推送、部署和发布使用对应授权；说明实际结果与未执行事项，不声明未经验证的成功。
