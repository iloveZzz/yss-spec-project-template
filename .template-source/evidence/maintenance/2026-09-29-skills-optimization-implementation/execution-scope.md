# Skills 全面优化实施范围

依据已定稿计划及用户原始回复 `OK 确认按完整执行计划来实施`，在主仓与七个已登记子仓推进 W0–W6 的已授权本地工作。采用 maintaining-skills；共享 canonical、registry、验证器、发现适配、评测器、profile 适配及命中分发代码为允许写入面，投影与锁仅由既有脚本生成。主控独立执行；其他历史研究子 Agent 不承担本轮写入。

不修改用户级配置/技能、真实业务项目、历史研究/计划或审批记录。Git 提交、推送、发布未获授权。首批真实评测总限额为 24 次启动尝试/2700 秒 Agent 执行窗口/单次300秒；调用方跨变体和重试累计。达到边界时保存实际证据并提出全量预算，不能自增。

本轮实施整体按 L3 登记；产品 Spec、OpenAPI、Ticket 和业务 Context 对账为 not-applicable：模板源技能与工具维护，无产品业务词汇或流转。根 CONTEXT 合同已消费。执行状态及各仓起点、源码快照、已有未跟踪文件摘要分别见 progress.json 与 baseline-manifest.json。
