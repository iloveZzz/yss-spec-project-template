# Skill 与 CLI sync 内循环测量

- 环境：macOS arm64、Node.js 24.21.0；`create-yss-spec` 3.4.10；同一次本地工作树预备快照 `a6f0cfc0688b2671933df78dfac166f48853bc88d452a5aa48632abdff100132`。
- 隔离方式：把 CLI 复制到临时目录，在副本运行 `scripts/sync-template.js`，用该副本初始化 Git 和非 Git 实例。根仓及原 CLI 快照未被基准命令写入。
- 测量：`node scripts/bench-sync-efficiency.js <target> 5`；先热身 1 次，再对无变化 `buildSyncContext` + `applySyncContext` 运行 5 次。读取次数只统计父进程 `template/` 下 `fs.readFileSync`；Git 根查找次数统计父进程 `collectGitRoots`；最终项目校验仍执行子进程，因此耗时包含校验。

| 实例 | 5 次耗时 ms | 中位 ms | 模板读取中位次数 | Git 根查找中位次数 |
|---|---|---:|---:|---:|
| 非 Git | 314.1、300.7、286.0、319.3、278.7 | 300.7 | 4441 | 1 |
| Git | 368.7、326.7、318.3、304.0、288.3 | 318.3 | 4441 | 1 |

原始记录见 [non-git.json](./non-git.json) 与 [git.json](./git.json)。此前的全量分发快照测得 CLI 无变化同步约 1.49 秒、模板读取 12246 次、Git 根查找约 4083 次；当前预备快照采用按需 Skill 分发，文件集合已变，旧值只作历史背景，不能据此计算同比提速。正式固定提交分发快照仍需在源改动确定后构建。

## 同快照对照

为隔离同期的按需分发改动，另用预备快照 `7acabc61259cc801ecc097857b38f683319dc6003743ad70f55b48e1cf808af8` 建立两个临时 CLI 副本。对照版只恢复规划阶段的逐文件二次读取和逐路径 Git 根查找；其他代码、实例、模板快照及最终校验相同。两版各热身 1 次、记录 5 次，原始结果见 `control-*.json`、`optimized-*.json`。

| 实例 | 对照中位 ms | 优化中位 ms | 模板读取次数 | Git 根查找次数 |
|---|---:|---:|---:|---:|
| 非 Git | 348.3 | 330.4 | 4791 → 4441 | 362 → 1 |
| Git | 373.8 | 328.6 | 4791 → 4441 | 362 → 1 |

这组对照只量化 CLI 规划中复用文件字节和 Git 根的收益；Skill 投影跳过重拷贝及项目校验同进程复用由场景测试验证。耗时不是 CI 阈值。
