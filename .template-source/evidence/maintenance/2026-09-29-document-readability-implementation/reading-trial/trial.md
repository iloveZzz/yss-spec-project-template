# 阅读试验：6 个短任务

请逐项打开对应材料，开始时计时，作答后停止。记录每题用时（秒）、答案及是否拿不准。不同题使用不同材料；不要先查看另一种展示。答案不足可以写“材料不足”。本试点由实际使用者作答，不能用 Agent 模拟。

| 顺序 | 材料 | 问题 |
|---|---|---|
| 1 | [A 原状态](A-status-old.yaml) | 当前阶段和下一工作单元是什么？阻塞是否有登记？能否据此判定已经批准、可执行？ |
| 2 | [B 新状态](B-status-new.md) | 当前阶段和下一工作单元是什么？阻塞是否有登记？能否据此判定已经批准、可执行？ |
| 3 | [A 新规则](A-rules-new.md) | 被引用时能否删除？成功的前提是什么？谁能修改口令，开发者能否读明文？ |
| 4 | [B 原规则](B-rules-old.yaml) | 被引用时能否停用？成功的前提是什么？谁能查看密钥，运维员能做什么？ |
| 5 | [A 原差异](A-diff-old.md) | 哪些业务条件改变了？哪些来源绑定改变了？可以自动沿用批准吗？ |
| 6 | [B 新差异](B-diff-new.md) | 哪些业务条件改变了？哪些来源绑定改变了？可以自动沿用批准吗？ |

回复格式：参与者姓名或角色；1～6 各题“答案；用时 N 秒；不确定点”。比较每对任务正确率与耗时；关键规则不能新增遗漏，整体正确率不得下降，配对耗时中位数须改善。未完成实测前保持 manual。
