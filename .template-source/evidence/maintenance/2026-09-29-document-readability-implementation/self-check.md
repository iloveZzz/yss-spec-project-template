# 维护者自检与返工记录

实际样例暴露出一处错误：对象列表里的 context_id 是外键，不能当成本列表的唯一 ID。修复后，重复检查和差异对齐按集合的正式身份字段处理；两个对象属于同一责任区的反例已通过，真实领域战略预览也通过。规则、失败、否定、未知字段和零值仍完整呈现。

实际打包初始化发现最小实例遗漏 reading schema，已在 create-yss-spec 的 COMMON 资产闭包补齐，并加入初始化后直接启用阅读的回归。三专职模板只分发 wire schema，没有安装上游阶段设计技能。

Agent 成本检查发现默认逐字段来源索引过大，改为 --model --json 显式展开。默认 JSON 减少重复绑定，关键原文与检查结果保留。尚未进行真实 Agent 效率评测。

独立审查未请求，本记录是维护者自检，不冒充 Reviewer 或人工可读性试验。没有修改既有批准、审批门禁或历史快照。模型辅助判断仅限此工程审查，真实试验和 committed 来源门禁保持待完成。
