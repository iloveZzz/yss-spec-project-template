# 低保真演练操作观察

来源：patterns-browser.json；三候选均为维护教学样例，没有真实用户批准。

Chromium 与 WebKit、1440×900 与 390×844 均完成同一失败任务：首次处理失败、输入与选择保留、重试、处理剩余资料、重置恢复初始数据。三候选采用相同 JSON 和 Token。

| 候选 | 脚本观察 | 选择代价 |
|---|---|---|
| 逐项 | 第一次 M-001 失败后重试，再逐项处理 M-002/M-003；完成后集合为空 | 保留全列表对照，但重复提交 |
| 批量 | 选择全部，首次提交失败，选择保持；第二次提交完成全部 | 操作集合需清楚，误选风险更高 |
| 队列 | 首次失败留在当前项；重试成功后进入下一项，逐项完成 | 集中核对，缺少同时查看全局的上下文 |

这些是确定性操作观察，不是人类耗时或效率统计。条件性教学选择仍为“允许批量、同质资料且需要整体核对时采用批量”；改变条件须重新判断。候选没有实际用户选择记录。
