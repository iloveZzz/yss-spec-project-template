# 维护者自检

本轮为 L3 模板维护，自检不替代独立审查或正式发布验证，也不声明生物人批准。

- 摘要：稳定 ID 语义基线不改；原始字节、完整返回内容、身份及读取集合绑定当前来源。同次执行内复用，返回前复核。
- 权限：v1 正式合同保持原约束；v2 只能 Explorer 分诊、空写边界、无阶段流转。真实文件/忽略文件/Git 索引及已初始化子仓前后观察、原任务绑定和运行日志摘要已覆盖。没有 OS 沙箱或防恶意证据所有者伪造的额外声明。
- 验证：shadow 原执行集合不变；资格为空时 allowlist 不启用；未声明完整依赖的检查保留。candidate/release 合并实际改动，candidate 缺基线则全量，限定 fast 明确 limited。
- 材料：完整来源和未知约束保留；同版本字节冲突、过期绑定和原决定缺口可定位。所有预填输出 execution_allowed/approval_reusable 均为 false。
- 测量：实际退出码、文件日志、总墙钟耗时与去重记录；不可观测量为 null，不把字符换算 Token，不累加并发耗时当作等待。
- 兼容：四个 CLI 由本地工作树快照验证，不宣称固定提交发布；专职源保留正式合同规则。初始化仍按入口闭包分发，历史实例/批准无自动迁移。

针对性测试 27 项通过；现有合同视图/validation-phase/跨 Profile 视图 5 项通过。详见 focused-tests.txt、contract-regression.txt。完整检查及分发集成结果另见 validation-summary.md；失败或未执行项不被这些局部结果替代。
