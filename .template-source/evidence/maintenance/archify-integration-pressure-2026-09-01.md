# Archify 集成压力场景证据

日期：2026-09-01

YSS 安全包装器覆盖并通过 8 个场景：

1. 拒绝稳定输出到仓库模式允许根之外。
2. 拒绝覆盖允许根中的非 Archify HTML。
3. 拒绝覆盖非 YSS Archify receipt。
4. 拒绝通过允许根内的符号链接把产物写到仓库外。
5. 拒绝 `--open` 交互式交付。
6. 正常生成 project-instance 的 JSON / HTML / receipt 三件套。
7. 正常生成 template-source 的维护证据三件套。
8. 验证 YSS override 明确禁用上游运行时更新检查。

第 4 项首次执行时真实失败：请求路径位于仓库内，但符号链接解析到系统临时目录后被错误地当作临时交付。修复后，包装器先按请求路径识别仓库合同，再检查解析后的真实输出路径，主模板和战术模板均 8/8 通过。

兼容性压力：上游全量套件在本机默认 Node 23 下有 2 个 `clean-skill-staging` 用例受 `fs.rmSync` 运行时差异影响；按上游维护环境 Node 22 复跑完整 1021 项后为 994 通过、0 失败、27 跳过。该差异不属于 YSS 包装器代码，但已作为运行时约束保留。

分发压力：完整 vendoring 明显增加两个 npm 包体积，当前压缩包分别约 15.13 MB 与 14.92 MB。用户明确选择完整包，因此本轮接受该成本；后续升级需继续观察 npm 发布限制与安装耗时。
