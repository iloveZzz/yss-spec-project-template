## 自检与反例

正式 checkpoint CLI 的技术切片、父 Ticket 反例修改前均退出 1（断言发现工具错误接受），修复后通过。会签库缺用户决定反例修改前因未抛错而退出 1，接入当前决定校验后通过。源码及针对性测试围绕公开 CLI / 会签 / 交接 seam；没有把探针采集退出 0 当成验收通过。

当前设计：checkpoint 是唯一状态源；禁止本地工程资产与实现状态；导航过期不反向更改批准。确认绑定当前资产、原始来源、身份、范围及摘要；交接复用逐项校验资产与专业边界，不创造新回复。独立交付快照在确认之前固定，避免确认记录与最终包循环计算摘要。

本轮自检不称独立审查。模板维护日常使用 self-check；产品业务会签与真实用户决定仍强制。上下文对账：not-applicable（模板维护不流转实例业务资产）；各仓现有 Context 合同由模板套件核验。
