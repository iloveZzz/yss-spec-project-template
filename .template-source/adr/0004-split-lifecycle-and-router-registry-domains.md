# ADR-0004: 分离生命周期注册域与 Router 合同域并迁移到 schema v2

> 状态：proposed。当前仅有 `schema_version: 1` 的生命周期结构注册表 shadow 校验；v2 迁移尚未实施。

生命周期控制和实现合同编译具有不同的变化频率与责任边界，因此拟采用一套逻辑治理体系下的两个结构化职责域：生命周期注册域定义主阶段、门禁、产物、工作单元、证据、状态迁移和人工交互，Router 合同域定义实现子合同、技能闭包、写路径与验证约束，两者只通过稳定 ID 引用。后续 schema v2 迁移应提供 v1/v2 读取、dry-run 迁移和冲突时 fail closed；验证通过后才允许只写 v2，并保留来源版本、迁移证据和回滚引用。在上述运行时资产与迁移验证落地前，本 ADR 不构成已完成的发布能力。
