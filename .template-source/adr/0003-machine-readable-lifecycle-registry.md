# ADR-0003: 使用机器可读生命周期注册表作为结构化事实源

> 状态：部分实施（Phase 1）。本次发布只接受注册表、稳定 ID、结构表和工作单元表的 shadow 校验；数量、索引、依赖图和测试 fixture 的完整生成属于后续提案，未实现前不得作为模板发布能力宣称。

YSS 研发操作系统当前在 Markdown 生命周期地图、主控 skill、机器契约、用户指南和场景测试中重复表达阶段、门禁、产物与工作单元，已经出现门禁数量和工作单元数量漂移。Phase 1 引入生命周期注册表，集中保存这些结构事实及稳定标识，并由它派生当前 Markdown 结构表；Markdown 继续承担人工解释和审查，ADR 继续记录取舍，业务语义不被压缩成难读的配置。数量、索引、依赖图和测试 fixture 的自动生成必须在独立 Phase 中与生成器和校验器一并落地，不能只通过 ADR 宣告完成。
