# 技能投影与锁定

技能投影是从权威共享技能生成、供特定 Agent root 加载的同步副本；锁文件对技能名做 derived 摘录，见 `wiki/raw/skills-lock-names.md`。`.agents/skills` 是跨 Agent 共享技能的唯一权威内容；`.claude/skills`、`.codex/skills`、`.cursor/skills`、`.pi/skills`、`.qoder/skills`、`.trae/skills` 中的同名共享技能是生成投影，禁止分别手工修改。Cursor 的契约运行时入口是 `.cursor/skills`；不得把 canonical `.agents/skills` 与某个平台投影当作同权双入口。

`skills-lock.json` 是技能清单、来源、版本、哈希和投影目标的权威记录，当前 `version` 为 `3`，`canonicalRoot` 为 `.agents/skills`。字段包括 `upstreamHash`（可追溯时的未适配上游内容哈希）、`effectiveHash`（当前生效的完整 skill 目录树哈希）和 `targets`（应投影到的 Agent roots）。只属于某个平台的 skill 由锁文件 `platform` 分组记录。共享技能名以锁文件为准，派生摘录见 `wiki/raw/skills-lock-names.md`。

新增共享 skill 必须先执行 `scripts/update-skill-lock --add=<name>`，再运行 `scripts/sync-skills` 与 `scripts/update-skill-lock`。新增平台专属 skill 使用 `scripts/update-skill-lock --add-platform=<root>:<skill-name>`。脚本不会把工作区中偶然出现的未跟踪目录自动纳入发布清单。单独检查使用 `scripts/sync-skills --check` 与 `scripts/update-skill-lock --check`。

核心技能默认可发现；专项技能由 [[YSS路由与合同编译]] 按影响面选择；试验技能不进入默认闭包。`docs/agents/yss-skill-registry.yaml` 当前 `status: active`，实现合同编译器 与生命周期编排器只消费通过该表校验的 canonical 技能。`llm-wiki` 已在该表登记为 `layer: core`、`maturity: verified`、`instance_default_discoverable: true`、`impacts: [quality]`，并已写入锁文件 `shared` 分组（`source: project`）；它仍不是 `yss-public-skills.json` 条目。

YSS 技能的公开发布仓库为 `iloveZzz/yss-spec-dev-skills`，是 `.agents/skills` 的单向发布投影。公开清单只放 `yss-*` 工程技能；[[LLM Wiki]] 与 Matt 流程技能不在公开发布面。发布阻断校验是 `scripts/verify-template`（见 [[模板发布门禁与验证]]）。创建、修改或退役 skill 走 [[模板维护流程]] 的 `maintaining-skills` 与 L1 / L2 / L3。

Matt 上游 revision 见 [[Matt技能体系]]；YSS 专项规范见 [[YSS工程技能体系]]。入口纪律见 [[Agent入口规则]]。投影可以是指向权威目录的符号链接，也可以是完整同步副本。
