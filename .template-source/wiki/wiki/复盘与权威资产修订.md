# 复盘与权威资产修订

发布或阶段完成时判断是否需要复盘。架构返工、验证返工、IMPORTANT / CRITICAL finding 或人工确认延期出现时，记录简体中文复盘并将发现回流到对应权威资产。

`artifact.retrospective` 属于 `stage.verification-release-retrospective`，在发布后或阶段性完成后命中复盘条件时形成。项目实例的 `work-unit.release-and-retrospective` 消费已审查候选、发布窗口与回滚点，输出发布 / 回滚证据和复盘记录；人工发布裁决、Fresh Verification 和治理回流均完成后才结束该工作单元。

复盘材料应绑定本轮实际命令、结果与时间，以及可追溯的变更边界、发布记录和恢复动作。当前验证才支持完成结论，旧成功记录或执行者自述不能替代，见 [[Fresh验证与独立审查]]。

| 发现涉及的事实 | 修订位置 |
|---|---|
| 稳定词汇及含义 | 根 `CONTEXT.md` |
| Agent 入口红线 | `AGENTS.md` |
| 阶段、门禁、产物、工作单元与稳定 ID | `.template-spec/process/lifecycle-registry.yaml` |
| 影响面、not-applicable 与模板维护强度 | `.template-spec/process/harness-process-tailoring.md`、`.template-source/process/maintenance-intensity.yaml` |
| Skill 来源、版本、投影与路由 | `skills-lock.json`、`.template-spec/agents/yss-skill-registry.yaml` |
| 数字人角色、运行时与会签 | `.template-spec/agents/digital-human-roles.yaml` |
| 视觉规范 | `DESIGN.md` |

其他阅读视图与导航引用这些权威资产，不重复定义规则。稳定业务语言由根 `CONTEXT.md` 持有；Wiki 等持久阅读视图据当前来源更新，见 [[LLM Wiki]] 与 [[技能投影与锁定]]。

模板源修订围绕可复用流程、工具、模板和技能推进，不生成具体产品 Spec、原型、OpenAPI 或垂直切片。提交与推送仍需用户授权；发布、商务承诺及运行时外部副作用由生物人决定。复盘不授予上述权限。
