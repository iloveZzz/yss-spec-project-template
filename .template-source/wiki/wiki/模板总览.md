# 模板总览

YSS Spec Project Template 是 Matt Pocock Engineering Skills × YSS × OpenAPI 驱动的轻量 AI 研发文档模板。当前仓库是 Harness / 研发管理仓库，默认承载流程文档、契约模板、Agent skills 与协作约定；运行时代码优先位于已登记的独立实现仓库。

只有用户明确选择让本仓库承载实现代码时，才使用同源的 `apps/backend/<project>/` 或 `apps/frontend/<project>/`（`harness-apps`），或以 Git submodule 挂到同一 `apps/` 布局（`git-submodule`）。`apps/backend/` 与 `apps/frontend/` 只是项目容器；`app/backend/`、`app/frontend/` 及其子路径禁止作为工程输出。跨仓登记与切片绑定见 [[实现仓库与跨仓库契约]]。

任务开始必须先读根目录 `yss-project.yaml`。当前仓库 `repository_mode` 为 `template-source`，走 [[模板维护流程]]，不默认生成具体产品的 Spec、原型、OpenAPI 或垂直切片 Ticket。`create-yss-spec` 创建或接管的产品仓库写入 `project-instance`，再进入 [[产品研发生命周期]]；CLI 只管理研发管理资产，不接管前后端运行时代码。身份判定细则见 [[仓库身份与路由]]。

单一事实来源不得在 README 或用户指南里另写一套：领域与流程词汇以 `CONTEXT.md` 为准（中文术语加 PascalCase `英文标识` 词干，见 [[Agent入口规则]]）；Agent 入口、硬门禁与禁止事项以 `AGENTS.md` 为准（见 [[Agent入口规则]]）；主阶段、门禁、产物、工作单元、证据和稳定 ID 以 `docs/process/lifecycle-registry.yaml` 为准；技能清单、来源、版本、哈希和投影目标以 `skills-lock.json` 为准（见 [[技能投影与锁定]]）。

`.agents/skills` 是跨 Agent 共享技能的权威内容；各平台 root 中的共享技能是生成投影。模板发布阻断门禁是 `scripts/verify-template`，且与外部 `create-yss-spec` 的跨仓库契约未完成集成验证时不得声称可发布（见 [[模板发布门禁与验证]]）。本地知识库的 init / refresh / rebuild，或要把研究结果落成持久 wiki，走 [[LLM Wiki]]（落成持久 wiki 用 `ingest`；已映射 live 源变了用 `refresh`）；一次性一手资料笔记仍走 `research`。本仓 wiki-root 为 `.template-source/wiki`，不随 CLI 快照进入 `project-instance`。
