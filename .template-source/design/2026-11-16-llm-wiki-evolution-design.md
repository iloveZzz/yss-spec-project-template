- 沿用现有显式调用、查询只读、人工内容保护、来源追溯和实际动作授权约定。

交付范围为技能正文、参考、约定模板、既有副本及相关元信息。本仓不维护或分发脚本与测试套件。提交、推送、部署、发行及向外部发送内容使用对应动作的真实授权。

## 增量一，知识综合与证据维护

### 页面组织与实体消歧

提供来源摘要、实体、概念、主题综合、决定五类内容示例，按资料选择，沿用既有目录和 Markdown 约定。页面独立存在应有独立读取价值，来源数量和页面链接数量均由实际内容决定。

创建或合并前读取已有定义、标题和别名，再核对对象类型、身份、组织、语境及适用时间。同名、缩写相同和语义接近作为候选线索。身份依据不足时保留歧义并说明候选，已确认同一对象时复用规范页面。合并同时处理旧入口、相关引用及人工正文。

### 摄取与持续综合

1. 读取来源、现有索引和相关页，核对本次允许的资料与写入范围。
2. 识别新增事实、条件、例外、反例、分歧及重复信息。同源转载追溯共同出处。
3. 将信息合入已有对象和主题，更新整体认识、适用范围、分歧及开放问题。只有独立阅读价值成立时创建页面。
4. 给关键结论附实际支撑位置，更新必要导航，按已有约定简记实质变化。
5. 回读本次正文与链接，说明实际影响、冲突及尚未覆盖内容。无实质信息变化时保持内容稳定。

综合时先检查来源的时间、版本、对象和适用范围。属于演变的内容保留前后条件，真实分歧保留双方证据。人工段落沿用现有所有权保护。

### 证据与时间

关键主张使用现有链接、脚注或段落来源说明连接到实际证据。网页注明页面及可定位段落，文档使用章节或页码，表格注明工作表与区域，音视频使用时间戳，代码使用仓库、版本、路径或符号。当前工具只能取得粗粒度位置时如实说明。

复用来源摘要、综合页、生成答案或 Wiki 导出时，沿关键主张的证据链追溯到实际原始依据。多个派生页相互引用仍共享原有证据，自引用闭环和同一答案的再次摄取只保留其派生身份。原始依据缺失或链路中断时记录可核实范围。保存跨来源推断时保留支撑材料及推断性质，用户确认的决定附实际确认依据。

易变结论按需要表达记录时间、查证时间和事实有效时间，日期未知时保留未知。决定注明确认者、确认时间和适用范围，推断与用户已确认决定分别表达。原始材料、派生综合与已执行事实具有各自来源身份。

沿用来源文件本身的维护职责，已有业务文档或代码仍是所属仓的事实来源。必要快照仅在授权范围保存，并标明版本和获取时间。

### 来源变化与影响传播

来源身份、实际位置和内容版本分别核对。原、新路径之间有移动依据且内容或版本连续时，维护同一来源的定位关系。相同路径或 URL 的实质内容变化仍按更新处理，只有文件名相同的资料保留各自身份。

| 情况 | 对受影响主张的处理 |
| --- | --- |
| 内容更正 | 找出受更正片段影响的主张，按新证据核对并更新 |
| 版本替代 | 记录新旧有效范围、替代依据及历史解释 |
| 正式撤回 | 重新评估引用主张的可信范围，检查其他独立来源 |
| 暂时不可访问 | 记录可核实范围与访问限制，依据可读快照回答历史范围 |
| 用户明确要求删除或遗忘 | 按实际范围处理原件、摘要、综合、索引及已知派生副本 |
| 仅移除某个来源文件 | 核对是否涉及主张有效性、资料整理或明确删除，依据已知意图处理，关键歧义定点询问 |

先沿来源链接、来源摘要和相关引用盘点影响，继续核对已知受影响的派生层。例如来源支持摘要，摘要支持主题，主题又被保存答案引用时，后续层级均纳入影响检查。各层逐项核对其独立支撑，直到已知受影响页面均已处理或明确记录受限位置。共享页面根据剩余证据重新综合，失去唯一依据的主张在授权正文中撤下或标明待核实，并说明处理理由。实际覆盖受限时报告仍待检查的依赖。

剩余来源同时核对版本、适用范围和有效时间。恢复旧版的当前效力需要有效依据，新版撤回仅能证明已知撤回情况。旧版已失效且当前依据不足时，当前规则保持待核实，历史结论按其原有有效范围表达。

普通修订沿用旧来源与替代说明。用户明确要求清除敏感内容时，范围内摘要与变更记录也使用必要脱敏表述。Git 历史、远端和外部索引各有独立位置与权限，仅对实际处理过的位置报告结果。

遇到人工所有正文或越出授权目录的依赖时，报告受影响位置和可信范围，继续完成可安全处理部分。主张改写和删除受对应正文授权约束。

受保护正文中的旧主张受影响时，在已有且获授权维护的来源页、生成区域或导航处保留定位到该主张的失效说明。后续查询沿证据链读取当前状态，并按权威来源核验。缺少可写位置时保留人工正文，在当前任务报告受限位置，后续查询继续依据回源结果说明可信范围。此处理沿用现有 Markdown 和维护位置。

### 巡检方法

新增 `references/lint.md`，覆盖矛盾与分歧、陈旧结论、无来源主张、重复或混并、知识空白、断链及孤立页面。孤立页面结合目录入口和实际用途判断，缺少入链只构成检查线索。

每个发现包含问题位置、原文或来源位置、影响、确定程度及建议动作。矛盾提供双方主张并核对范围与时间。失效提供替代依据。知识空白说明哪些已有材料支持继续调查。

巡检注明实际读取范围。修复完成后回读本次相关内容，超出检查范围的页面保留未知。巡检可以使用现有文件工具，自动化能力以实际工具为准。

## 增量二，查询与持续使用

### 按问题检索

已有 Wiki 缺少 `index.md` 时，从用户指定目录内已有 README、目录、标题、正文与链接定位相关页面。沿用已有 Markdown、wikilink 和人工约定，索引缺失作为导航限制说明。查询在该目录内继续只读检索，更新请求可按实际需要补充已授权的导航。

| 问题 | 读取路径 |
| --- | --- |
| 具体事实 | 标题、别名和关键词定位，读取相关段落，回查证据 |
| 对象比较或跨来源解释 | 读取相关对象及综合页，核对各维度的来源、条件与反例 |
| 全局主题 | 从分类索引、概览和综合页定位主题，再抽查关键证据，说明覆盖范围 |
| 当前状态 | 核对最新可访问权威依据、有效时间和版本 |
| 历史状态或决定 | 读取对应时点的事实、决定及替代关系 |

先定位候选，再读取正文，依据证据缺口沿链接扩展。大索引按相关分类逐层读取。达到工具上下文限制、已能支撑当前问题或继续读取没有新增相关信息时停止扩展，并报告实质覆盖限制。没有可观测统计时以文字描述范围。

查询发现陈旧页、错误或可沉淀结论时在回答中说明。用户要求保存成果时再进入已授权摄取路径，复用已有主题并附证据。

回答区分直接证据支持的事实、跨来源推断和未知。引用派生页时核对其原始依据和当前失效说明，来源链中断、原件撤回或有效期变化均影响该主张的可信范围。

### 多格式输入

发现来源时记录原件位置、可读性、抽取方法及缺失内容。PDF、扫描件和 Office 优先复用宿主已有工具，复杂材料可评估 Docling。抽查标题层级、阅读顺序、表头、单位、跨页表格和图片说明。关键内容抽取失败时，仅综合实际读到的部分，并记录影响。

抽取结果保留能支持回源的位置。附件处理和模型调用继续受本次资料范围与数据授权约束。

### 整理与中断恢复

整理时根据实际重复、篇幅和读取用途决定合并、拆分或归档，维护旧引用和必要导航。恢复中断摄取时先复读已写页面、索引及现有记录，识别已完成修改与遗漏，核对新出现的人工变更后续办。重复执行应保持来源和主题稳定，并继续保留冲突证据。

来源或页面移动时记录原、新位置的对应关系。入链和出链均按所在页面的实际目录解析，跨目录移动后重算相对目标，并核对标题锚点、片段和既有 wikilink 的真实目标。同名目标存在歧义时按内容与身份消歧，整理后重复摄取应继续复用已有对象。

## 验收场景与观察方式

以下是未来实施时的代表性演练输入与判据，覆盖正文方法和适用副本。演练记录在当前任务或已有维护说明，结果标明实际宿主、读取到的技能路径及限制。

| 场景 | 预期行为 |
| --- | --- |
| 同一来源重复摄取，同源文章被转载 | 来源与主题保持去重，独立证据数量符合实际出处 |
| 保存答案或 Wiki 导出被再次摄取并形成互链 | 派生身份和原始证据链保留，独立支撑按真实来源判断 |
| 新来源补充条件并提供反例 | 已有主题认识更新，条件与反例可回源 |
| 两个同名实体，或中英文别名指向同一对象 | 身份依据充分时归一，否则保留歧义 |
| 来源因时间、版本或适用范围看似冲突 | 演变与真实分歧得到对应表达 |
| 撤回唯一来源，或撤回共享来源之一 | 分别重评失去依据的内容与仍受支持内容 |
| 来源经过摘要、主题再被保存答案引用 | 已知受影响派生层均被核对，受限依赖得到说明 |
| 新版来源撤回，剩余旧版已失效 | 当前规则保持待核实，历史规则保留有效范围 |
| URL 暂时不可访问 | 回答保留核验限制，已知事实的处理有依据 |
| 人工正文参与撤回，用户明确要求删除敏感资料 | 依据段落授权处理，结果覆盖实际已知派生位置 |
| 受保护旧结论失效后重新查询 | 正文受保护，已授权位置保留影响说明，回答依据当前证据 |
| 只查询、只检查，以及查询并保存 | 前两者保持只读，复合请求完成对应保存 |
| 巡检发现潜在矛盾、孤立页和知识空白 | 发现带证据、覆盖范围与确定程度 |
| PDF 表格缺单位、抽取失败或上下文截断 | 保留资料缺口，结论范围与实际读取一致 |
| 摄取中断后重试，同时发生人工编辑 | 已完成内容得到复用，人工变更受保护，遗漏得到补齐 |
| 已有 Wiki 缺索引或使用 wikilink | 从现有页面只读定位，沿用实际结构 |
| 来源改路径、页面跨目录移动或同路径内容更新 | 来源身份连续，入链与出链可达，实质变化得到更新 |
| 普通文章总结、来源内嵌命令和 Wiki 范围外路径 | 行为遵循原任务及实际授权 |

内容核对证明方法、引用和分发一致性。实际宿主中的演练用于观察调用与执行效果。检索召回、答案支撑与更新一致性分别观察，收益需要用户真实资料中的后续使用证据。
