# A2UI 高保真原型技能规格

产品设计者需要将同一业务对象按用户当前意图展示成不同结构，并在浏览器中验证用户动作。上一轮跟进提醒验证使用 Vue 3、shadcn-vue 和 A2UI 1.0，证明预设消息可以驱动布局变化和动作回传。本次把制作方法和可替换素材交给模板使用者，报名示范只用于演练。

## 范围与验收

| 使用场景 | 技能应交付的结果 | 验收方式 |
| --- | --- | --- |
| 根据已有规格设计动态界面 | 可运行的 Vue 3 原型、采用项目主题的 shadcn-vue 组件、相关场景的交互说明 | 从原型普通页面入口完成一条已确认任务，对照实际画面检查标题、顺序和操作反馈 |
| 同一记录需要另一种布局 | 使用 A2UI 1.0 消息创建界面、更新组件结构并绑定可变数据 | 切换后至少一个节点出入可见树。按钮携带当前记录上下文，返回后仍对应原记录 |
| 消息或动作不适用于当前场景 | 未映射的组件或无效消息有可见反馈，有效场景可恢复。宿主按当前对象和状态处理已声明事件 | 在有效场景后加入一个未映射组件，检查原画面仍可操作，再给有效输入；用错记录的动作不能完成切换 |
| 复用或调整原型 | 可换用真实规格、样例数据、组件和主题；说明采用的 catalog、组件子集、运行和模拟范围 | 从技能素材与既有设计资产在空目录组装示例；固定页面的普通样式改稿继续沿用原设计技能 |
| 采用 SCRM 前端既有组件 | 可按需组合折叠分区、计数备注框、表单提示和阶段流转预览 | 输入备注后能预览并返回同一草稿。清空回焦，可折叠分区可用键盘操作，只读和禁用字段保持原值。[组件说明](../../.agents/skills/yss-a2ui-prototype/references/scrm-components.md) |
| 选用 shadcn-vue 官方组件 | 72 个组件组都能按需装配，也能在同一个 Vue 3 原型里逐组预览。保留 SCRM 共用导出与业务组件 | 按[全量组件说明](../../.agents/skills/yss-a2ui-prototype/references/shadcn-components.md)生成单组和全集，遍历目录，并操作表格排序、日期选择、弹层回焦和跨目录动作 |

技能作为 Spec、Frontend 的按需能力，依赖已有的产品设计技能。交付范围为模板源码、平台副本与分发登记。示范使用本地预设消息，真实模型、生产服务与对外发行需要各自的任务授权。
