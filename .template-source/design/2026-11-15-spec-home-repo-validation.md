## 发现的问题与修复

| 问题 | 实际影响与处理 |
| --- | --- |
| HTTP 数据块拆开 Unicode 字符 | API 先收集原始字节，再严格 UTF-8 解码，避免按块转字符串破坏字符；增加跨块及非法编码请求检查 |
| 存储时间格式不合法 | 读取时校验 ISO 时间；损坏记录不能被当作正常数据继续覆盖 |
| 列表读取失败后仍可创建 | POST 成功后新项被错误页遮住且草稿清空；改为先恢复列表，保留可编辑草稿，按钮和 handler 同时阻止提交 |
| 写入结果未知被误报失败 | API 已保存、响应被丢弃时会错误引导重试；区分明确拒绝和未知结果，未知时保留草稿、重新读取供核对，不自动重发写入 |
| 未知创建结果与已完成筛选组合 | 已保存的待完成项被当前筛选隐藏；核对创建结果时切回全部，保留未知提示和草稿 |
| 存储文件含非法 UTF-8 | 非严格读取会把坏字节替换后继续覆盖；改为原始字节严格解码，错误返回 500，保持文件原字节 |

前两项在 v1 工程实现审查中修复。其余四项由独立复审发现，包含真实浏览器/HTTP 复现；复现记录不改写为通过记录。未知写入问题没有引入新的幂等协议，仍由清楚的结果提示和重新读取帮助用户判断。
