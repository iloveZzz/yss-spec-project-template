# 决策地图

仅用户显式调用，用于多个相互依赖的未知跨越一次会话的工作；简单需求不必建图。地图默认用于收敛决定，不隐含执行实现或对外发布授权。

先读取已有目标、范围和确认。地图是索引，决定详情留在原记录，以有意义的标题链接；不重复存储规格。已有 tracker 就沿用其真实能力，没有则在当前对话或用户约定的本地文档起草，不要求 setup 或治理身份。

按需要读取 [地图结构](references/map-format.md)、[决定类型](references/ticket-types.md)、[范围与依赖](references/scope-and-frontier.md)。建立新图见 [建立地图](references/chart-map.md)，推进已有图见 [推进地图](references/work-map.md)。用户业务决定必须来自真实回复，事实可独立调查，已有确认不重问。

所有远程创建、评论、分配、关闭或删除遵循对应授权；读取请求只整理和建议。缺权限继续完成本地准备，不自动调用其他显式入口、建分支或要求任务包。
