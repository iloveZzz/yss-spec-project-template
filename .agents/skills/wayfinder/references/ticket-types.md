# 决定类型

- 研究：问题等待事实，用 `.agents/skills/yss-research/SKILL.md` 查证并记录来源，不代答业务选择。
- 原型：需要具体产物判断，产品 UI 由 `.agents/skills/yss-design-system/SKILL.md`，限定逻辑/状态由 `.agents/skills/prototype/SKILL.md`；观察可以由 Agent 执行，用户选择必须来自真实回复。
- 澄清：问题等待业务取舍，用 `.agents/skills/grilling/SKILL.md`；词义歧义才用 `.agents/skills/domain-modeling/SKILL.md`。不自动重做整轮访谈。
- 支持工作：只有完成后才能作出决定的具体动作，按当前授权处理；不借此扩大到完整产品实现、付费注册、联系他人或泄露凭据。
