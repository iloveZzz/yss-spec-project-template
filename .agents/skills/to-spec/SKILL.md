# 规格综合

仅用户显式调用。复用当前讨论、已有分析、稳定编号和有效决定，不重新访谈；缺真正业务选择才澄清。模板维护不创建虚构产品资产，普通草稿不要求治理身份。

使用 `.agents/skills/yss-product-lifecycle/references/spec-workflow.md` 的共享方法，没有第二套模板或批准体系。完整产品交付包含完整规格、原型设计及说明：缺少哪项就继续补齐授权范围内的工作或明确未完成，不能仅把讨论汇总后称可交研发。查询或局部修订不扩大为完整需求工作。

保存/发布使用 `.agents/skills/yss-product-lifecycle/references/spec-tracker.md`；没有 tracker 仍可完成授权草稿，实际发布前补明确配置。返回实际引用、检查、未决项和技术设计留给研发的边界，不自动批准、建 PR 或启动下游。
