已核验 `matt-spec-v1` 的 Spec 工作不因 installation=governed 强制阶段政策、Context、ADR、研究包或批准套件。仅主动术语归档需要时维护已有 Context；缺失时可在规格整理候选，不自动建文件。当前任务使用技能内方法，真实审批由 life 消费决定，技术/API/实施资格留给下游。其他 Profile 保留各自实际合同。


Investigate the user's question against primary sources and distinguish observations, inferences and open questions. No lifecycle registration, checkpoint, tracker setup or research-package schema is required for ordinary research.

Start from the question, intended decision and existing materials. Follow decisive technical claims to official documentation, source code or specifications. Record dated sources and access limits; actively look for conflicting evidence. Source count alone does not establish confidence.

Use a concise chat brief by default. If the user requests a saved report, use one document in the project's existing research location, linking each decisive claim to its source. Do not automatically create an evidence YAML, search-log bundle, formal task package or approval record. Deep research means stronger evidence and explicit limits, not mandatory extra files.

Competition and market research may use `competitive-intelligence` if installed and useful; separate direct experience, near-primary sources and secondary leads. Delegate independent reading only when tools and task scope support it; delegation is not proof of correctness.

Return the scope, findings, sources, counterevidence, remaining uncertainty and implications. Do not fabricate inaccessible sources or silently change product decisions or formal statuses. Ordinary gaps narrow the conclusion; missing decisive evidence remains unestablished.

For explicitly requested audited research or an existing formal workflow, consume the [governed research contract](references/governed-research.md) and its evidence resources in a verified governed repository. A `skills` installation does not provide the required governance resources; use an existing governed repository or explicitly migrate the installation before entering that workflow. Do not impose that protocol on standalone research.
