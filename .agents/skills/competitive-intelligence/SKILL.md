# 竞品研究

明确需要支持的决定、目标用户、比较对象和范围。按用户要求给出简报、功能矩阵或深度报告，使用同一组实际来源，不要求研究双文件、证据协议或渲染脚本。

- 优先读取产品、定价、官方文档和更新记录；口碑资料标明日期、样本与来源局限。
- 比较功能、套餐、流程、集成、定位、投诉和替代方式，区分支持、部分支持、不支持与未知。
- 每个结论注明适用版本、地区和日期，资料缺失不能当作不支持。
- 推断与建议注明依据，保留反向证据。默认不做数字排名，用户要求评分时明确维度和依据。
- 只使用可访问或用户提供的资料，遵守授权，不把竞品专有内容直接复制为项目产物。

需要写入文件时可参考项目已有竞品矩阵或报告模板；模板是表达辅助，不是完成条件。输出结论、来源和未解决问题，不自动改动需求或发布内容。
