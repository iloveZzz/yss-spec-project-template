# YSS Skill Boundaries

> Generated by `scripts/generate-yss-skill-boundaries` from `docs/agents/yss-skill-registry.yaml` and `compiler-contract.yaml`. Do not hand-edit.

实现入口先选择 capability 或窄 Recipe，再由实现合同编译器计算最小 skill 闭包。下面是派生阅读视图，不是第二套路由事实源。

## Dependency Semantics

| Type | Compiler behavior |
| --- | --- |
| `context-required` | 自动递归加入执行上下文。 |
| `context-conditional` | 仅当显式 condition 命中时递归加入。 |
| `coordination-only` | 记录协作原因，不扩张执行上下文。 |
| `review-only` | 仅作为审查输入记录，不扩张实现上下文。 |
| `component-dependency` | 记录组件关系；由 capability/Recipe 显式选择，不自动加载。 |
