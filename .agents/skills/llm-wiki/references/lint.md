# Wiki 巡检

用于用户要求检查 Wiki 的情况。先确认指定目录和问题范围，读取现有导航与相关正文。缺少索引时从目录、标题、正文和链接继续定位，沿用已有结构。

普通文件纯检查保持文章、索引、日志、缓存和反馈文件只读。用户已要求修复时，直接处理对应授权项，来源变化读取 [摄取方法](ingest.md)，正文和人工保护读取 [写作方法](writing.md)。

已授权使用 QMD 辅助定位时，知识文件保护与专用派生状态写入按 [QMD 方法](qmd.md) 处理。严格要求全部状态零写入时使用现有文件检索，巡检发现仍须回到实际原文和证据。

## 检查内容

| 项目 | 判断依据 |
| --- | --- |
| 矛盾或分歧 | 给出双方主张与来源，先核对对象、版本、时间和适用范围 |
| 陈旧或失效结论 | 给出替代或撤回依据，沿已知派生层检查影响 |
| 无支撑主张 | 沿证据链回到原始依据，检查摘要、生成答案和互链的派生身份 |
| 重复或实体混并 | 对照对象身份和重叠内容，别名只作为检索线索 |
| 知识空白 | 说明已有材料引出的重要问题与缺失证据 |
| 断链 | 按所在页解析目标，核对相对路径、锚点与既有 wikilink |
| 孤立页面 | 结合目录入口与实际用途判断，缺少入链作为检查线索 |

每个发现给出问题位置、原文或来源位置、影响、确定程度及建议动作。引文存在只能证明该文字可定位，语义判断继续核对其条件和实际支持范围。

## 结果与修复

说明实际读取范围、发现与剩余未知。潜在矛盾和无法回源的主张保留核验限制，只有已读范围才能形成检查结论。

已授权修复后回读相关正文、证据和链接，保留人工编辑与范围外依赖的处理限制。建议补充外部资料时给出调查方向，实际搜索、摄取和写入沿用户当前授权执行。

使用已有文件工具即可完成适用检查。工具检查结果只覆盖其实际规则，方法演练和宿主执行结果按实际证据说明。
