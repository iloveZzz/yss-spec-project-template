# 组件检查并入现有评审与六轴 QA

低保真只核对任务、数据、入口/出口、状态、选择范围及恢复规则，不要求提前确定组件外观。高保真消费已评审行为；组件接入导致业务行为变化时回到受影响的低保真评审。

| 现有 QA 轴 | 本轮组件检查 |
|---|---|
| visual | 当前 DESIGN 角色与计算样式；compact/comfortable、正文、Field/InputGroup 内外边框；文字及状态对比度；同内容、同状态、同视口前后截图 |
| layout | 分组、筛选/结果/选择反馈；详情侧栏和操作区；390px 摘要/单列；表格内滚动；保持项不得自动重排 |
| interaction | 分页与筛选/空态/跨页选择一致；菜单禁用和执行结果；失败重试、取消确认、完整重载及再次保存；切换/重置清除临时状态 |
| content | 标签/帮助/错误关联；权限与部分失败原因持续显示；加载/空态下一步明确；未模拟动作禁用并说明 |
| accessibility | 纯键盘、首错焦点；Sheet/Dialog 标题、Escape、关闭与焦点返回；菜单 Arrow/Enter/Escape；实际点击区域及相邻间距；200% 浏览器缩放；减少动效计算结果 |
| cross-platform | Chromium 两个核心视口，WebKit 关键链路；独立目录断网 file://；资源、console、深链接与非法场景 |

每项记录通过/失败/未执行/有理由的不适用。行为缺陷（例如草稿丢失、禁用项能执行）必须修复；视觉观察绑定规范或保持项和证据；偏好建议保留为非阻断建议。控件高度、组件库默认能力、初始化消息或 smoke 通过均不能替代适用检查。工程结论与用户视觉确认分开。

## Vue 与组件真实性

核对 `component_basis=vue-shadcn-prebuilt`、固定 shadcn-vue revision、Vue/Reka 依赖和实际使用源码清单；不能把 React 或原生 select 称为 Vue 组件。产品下拉、菜单和浮层优先实测组件交互；原生例外记录目的。Select 验证键盘选中、Escape、焦点返回和触发器宽度；Sheet 验证完整标题说明、取消路径和来源焦点。场景切换后不得遗留 Teleport 浮层。Blocks 的新行为与依赖必须有当前任务依据。

## 企业多页工作区

并入既有六轴：visual 核对 workspace 角色与标题层级；layout 检查流式工作区、空详情不占位、主/详情/表格滚动和窄屏 Sheet；interaction 覆盖导航同步、页签去重/关闭回退、dirty 取消/放弃、跨页保留和全量重置；content 明确内存草稿与来源场景；accessibility 检查页签键盘、隐藏页及 Teleport 不可抢焦点、关闭与详情返回；cross-platform 复验桌面/平板/窄屏及离线。发现草稿丢失、非法入口回退或未执行关键链路时保持阻塞。

页面 Tag 补查：导航语义和 aria-current、按钮不嵌套、当前/悬停/焦点区分、方向键不自动切页、Enter/空格激活、Delete 和关闭按钮触发同一草稿确认；溢出后当前 Tag 与焦点可见，窄屏菜单能访问全部打开页面。收起导航检查图标对齐、当前项、Tooltip 背景/箭头一致及切换后清理。页内 Tabs 保留标准键盘语义和无填充指示线，不能与页面 Tag 混用。源码与构建检查不能充当实际焦点、计算样式或视觉验收。

## 搜索、日期与研究增量

- interaction：搜索文字不冒充已选 ID；中文组合输入不误提交；同名 ID 可区分；加载/失败保留旧值与搜索词。未完成或逆序范围不能应用；取消/Escape 不修改正式值；清空与应用分开。跨页保留草稿与条件，隐藏 Teleport 不抢焦点。
- layout/accessibility：单独记录 320 CSS px 重排及实际 200% 缩放；外围筛选、分页、浮层与主操作可达，二维表格例外不外扩；实测点击区域/间距及焦点遮挡。原触发器消失时应有明确逻辑后继。按 `yss-design-system/references/search-date-theme.md` 选择读屏检查并记录版本及未执行项。
- content：设计疑问写成无提示任务和可复核结果。真实研究与教学模拟分开，缺参与者或轨迹不能宣称收益。工程报告只引用到同一份 design-qa。

维持行为缺陷、规范/保持项对应的视觉观察、非阻断偏好建议三种结论。缺环境导致的必要检查未执行必须阻断对应验收；工具成功不能替代人工视觉批准。
