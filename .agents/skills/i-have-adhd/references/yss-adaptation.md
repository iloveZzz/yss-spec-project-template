# i-have-adhd 的 YSS 适配

上游：`ayghri/i-have-adhd`；固定 revision：`7b9069b39972e269e61bd95c2f66ebb90cac6a02`；许可证见技能目录 `LICENSE`。

原始文件来自 [固定版本目录](https://github.com/ayghri/i-have-adhd/tree/7b9069b39972e269e61bd95c2f66ebb90cac6a02/skills/i-have-adhd)。未经改写的来源基线保存在模板维护证据中；`upstream-files.json` 记录逐文件 SHA-256，`skills-lock.json` 记录上游目录哈希和当前技能目录哈希。基线不进入实例默认加载面。

| 上游行为 | YSS 适配 |
|---|---|
| 用户显式调用、会话持续 | 原技能名保留；文档工作按 `lifecycle-document-output` 条件调用，任务结束即失效 |
| 对读者作 ADHD 假设 | 面向所有文档读者，不引入诊断假设 |
| 行动前置、步骤编号、删除套话 | 消费中文写作规范，按产物类型决定信息顺序和格式 |
| 展示进度、下一步和具体时间 | 报告实际变化和全部必要阻塞；时间有依据才估算，不把工作推给用户 |
| 压缩可见列表 | 完整性优先，不设规则数量上限 |
| 原因与修复直接陈述 | 区分已知现象、待验证原因和实际验证结果 |
| 平台专属 agent 配置 | 不安装上游 Gemini 持久提示；项目 OpenAI 配置只描述当前文档配套用途 |

生命周期仍拥有门禁、状态、批准和资产；本技能没有独立授权、审批或分支流程。正文规则只在 `docs/process/document-writing.md` 维护；本文件只解释来源差异。

注册表将本技能声明为模型可调用、实例默认可发现的通用工作流 core 技能（仍只作为文档配套）；调用者以条件依赖加载。上游 `disable-model-invocation: true` 在适配版移除；作用域由本技能触发条件限定，不延续上游会话开关。

验证只证明来源、路由、投影和合同符合预期。中文文档质量需通过真实生成评估，不以结构检查或作者自检代替盲评效果。
