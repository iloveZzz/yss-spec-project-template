# 按需产品设计

根据产品问题开展设计，使用 [按需设计规范](references/spec-design.md)。读取项目已有设计、页面和组件约定；缺规范时提出可审阅的设计建议，不虚构已有规范或批准。

按任务补充读取：新项目浏览器高保真使用 [Vue 原型准备](references/shadcn-vue-prototype.md)，新后台且无设计基线时参考可调整的 [高保真主题](references/high-fidelity-default-theme.md)；Vue 组件与主题适配见 [组件库适配](references/vue-library-adaptation.md)；页面组织见 [页面组合](references/page-composition.md)；普通设计评议见 [设计评议](references/design-review.md)；核对已有 YSS 主题见 [主题检查](references/design-qa-theme.md)；模板基线维护见 [主题来源与维护](references/data-quality-theme.md)。相应历史原型合同的主题细节见 [原型默认主题](references/prototype-default-theme.md)。

独立使用时按任务选择线框、高保真或必要的交互原型；新项目高保真默认使用 Vue + shadcn-vue 的浏览器页面，用户可要求其他形式；其他产品设计技能可用时按需协作。已有正式合同继续按原合同核验；普通设计不要求预先选择 H1/H2、OpenAPI、生产组件或固定 QA 矩阵。

只对当前产物及声称的范围检查。静态视觉不证明交互，原型操作未执行不写通过；复杂状态或业务规则交回产品设计与 Spec，不通过视觉润色替用户决定。

设计成果保存到项目约定或用户指定的位置，没有约定时在当前任务目录新建清晰的设计目录；不覆盖既有成果。返回设计来源、范围、实际检查、允许差异与未解决问题，不自行批准、冻结或授予实施资格。
