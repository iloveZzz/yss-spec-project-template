# 企业页面组合与主题适配

此文说明使用规范角色的方法。新 Spec 按当前产物和风险选用以下模式；先读取已有根 DESIGN.md 和相关页面保持项、交互说明或状态信息，缺规范时说明缺口。数值以已有规范派生变量为准；已采用的历史原型合同继续按原合同核验。

- 页面按任务阶段分组：筛选区回答范围，工具栏回答可执行动作，结果区回答对象状态，详情承接次要字段。Card 表示有独立标题/责任的区域，不以 Card 套 Card 制造层级；Separator 分隔相邻内容，不替代标题。
- 紧凑工具栏保持单个主操作；次要动作进入 DropdownMenu 时保留可发现入口。结果数、筛选范围、选中数量和剩余事项可扫描，窄屏按字段组换行，不压缩正文。
- Field 同时组织标签、说明和错误，错误定位到控件；长说明自然换行。InputGroup 只承载输入附加信息或相关操作，外层统一边框与焦点，内层禁止重复尺寸。
- Sheet 承接列表详情，Dialog 承接短决策，AlertDialog 承接现有合同要求的确认。标题、说明、退出和焦点返回齐全；窄屏操作不被浮层边缘遮挡。
- 持续权限/冲突/部分失败原因用 Alert，Badge 仅补充状态。Tooltip 不承载唯一必要信息。Empty 给原因和下一步，Skeleton/Spinner 配可读加载状态。
- 指标只突出任务相关主次；Tabs 不隐藏必须同时比较的信息。必要横向表格保留关键列和滚动提示，外层页面不滚动溢出。

采用对应 YSS 历史原型主题时，新原型默认浅色 compact；comfortable 显式选择，既有局部修改遵守保持项。其他项目按其现有风格或任务选择密度，不强加此默认。YSS 映射层消费命名组件变体，不再应用生产 compact 算法；其暗色入口仅供历史参考，未完成当前规范验证。

原型技能可用时可参考其组件使用、状态和键盘配方；否则依据项目组件与当前任务检查，不能声称已执行未具备的原型验证。三组正反例见 [enterprise-craft.md](enterprise-craft.md)；模板源预览只展示主题与组件状态，不能当作已批准产品页面。

## Vue 高保真组件适配

已采用相应 YSS 原型合同的页面使用其登记组件；其他项目按现有组件与 [库适配](vue-library-adaptation.md) 选择。Select/Menu/Sheet 不删焦点环、禁用反馈或退出路径；组件原语的能力须按实际项目版本核验。玻璃仅用于已选择的局部表面，正文与表格保持稳定底色，实测背景合成对比度并支持减少透明；不把研究外观写成规范默认。

## 企业应用壳

以下应用壳和导航样式是对应 YSS 规范的示例；其他项目以自身页面与设计规范为准，可按任务调整，不强制采用。

模块导航 → 分组侧栏 → 已打开页面 Tag → 页面任务，只呈现真实可操作入口。已有 workspace 规范决定尺寸和标题；主工作区流式填充，表单内部保留阅读宽度，去除装饰性大标题与重复说明。详情选中后才占位，关闭归还空间；窄屏导航和详情不得挤压正文。主内容、详情和表格滚动职责分开，固定工具栏不遮住焦点和错误。原型技能可用时参考其工作区状态；否则记录实际设计和未验证行为。

页面导航 Tag 使用独立轮廓、主色浅底当前态以及分开的激活/关闭按钮；不套用页内 Tabs 下划线。页内 Tabs 只用主色文字和指示线，不叠加灰底分段控件。收起导航图标居中，当前项有标记，Tooltip 的反相背景与箭头一致。尺寸与动效读取根规范，减少动效时取消过渡。
