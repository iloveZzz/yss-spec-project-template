# YSS 标准亮色主题：默认采用与项目覆盖

无既有设计基线的企业后台默认采用本主题，不再每次从上游预设重新选色。完整规范及机器可读 Token 见 [默认 DESIGN.md](../assets/DESIGN.md)。模板仓根 `DESIGN.md` 为维护源，该文件为随技能安装的相同副本。

## 采用规则

1. 先读项目已有 `DESIGN.md`、Token、组件和已指定视觉稿；已有规范优先。明确要求迁移时按本次授权改规范和受影响页面，不批量覆盖其他项目。
2. 没有基线时使用 YSS 标准亮色；任务需要建立项目 `DESIGN.md` 时，以默认文件为起点，保留角色名与必要规则，写明实际采用的差异。只改局部页面不强制新建规范文件。
3. 主题定义值、页面引用语义角色。既有 Token 命名可用映射适配，不复制一套页面私有色值。营销页、品牌展示或用户指定风格不自动套企业后台主题。

## 关键默认值

| 角色 | 默认 |
|---|---|
| 品牌与操作 | `#0d6be9`；Hover `#0b60d2`，Active `#0955bb`；主按钮白字 |
| 页面 / 卡片 / 导航 / 表头 | `#eeeff3` / `#ffffff` / `#f6f9fe` / `#f8f8f9` |
| 标题 / 正文 / 辅助 | `#001949` / `#2c4068` / `#62728c`；placeholder 使用辅助色 |
| 边框 | 装饰 `#d9dde4`，分隔 `#eaecf0`，必要控件边界 `#7d8aa0` |
| 排版 | 正文 14/20，标题 20/30/600，表头与表格正文 14/22/400，辅助 12/18 |
| 控件 / 表格 | 默认控件 32px、表头 48px、新标准数据行基础 48px 且可自然增高；28px compact 显式选用 |
| 触摸 | 常用目标优先 44×44px；不把可见图标尺寸当点击区域 |
| 圆角与阴影 | 控件与浮层 4px；看板列 0；普通卡片、按钮无阴影，浮层按规范三层阴影 |
| 焦点 | 输入仅改变 1px 蓝色边框；InputGroup 外容器统一表达；其他键盘目标保留清晰轮廓 |
| 选项 | 选中蓝字 + 勾选；当前项灰底，键盘当前项再加左侧 2px 内嵌线，无整行粗框 |
| 留白 | 页面 / Card 16px，窄屏 12px；列表可选 12px × 20px，筛选列间距 20px |
| 图标 | Lucide SVG，常规 16px，提供可访问名称；遵循锁定包 API |
| 响应式 | `<720`、`720–<1200`、`1200–<1680`、`1680–<2160`、`≥2160` CSS px |

标准合并列表与销售机会页面的共性，弱对比文字和控件边界按可读性优化；Hover / Active 是设计值。原有反馈语义色保留，13 阶连续蓝按新主色派生，不能当分类色。阶段色 `stage-new/won/lost` 仅用于业务阶段，不替换成功/失败反馈。新版标准列表采用 48px 数据行；已有项目保留其选定密度。来源页面的历史核对不代表本次运行通过，未验证的业务卡片高度不作默认。

页签、组合筛选、日期、视图切换、看板及可选多级导航见 [标准页面模式](standard-theme-patterns.md)。它们按业务需要采用，不要求所有页面套三级侧栏或看板。

## 使用与修改

主题装配和可选密度见 [主题映射](prototype-default-theme.md)；组件来源和装配顺序见 [Vue 原型](shadcn-vue-prototype.md)。CSS 变量应覆盖 Teleport 弹层，使用本次实际项目的 Token 定义。

默认只支持亮色；暗色、历史 compact 算法快照、客户主题不自动进入默认值。修改模板默认时同步根规范、技能副本、亮色变量、兼容映射和平台副本；修改实际项目时只同步该项目采用的资源。比对实际默认、悬停、按下、禁用、焦点及窄屏状态，不把文档或颜色计算当成整页检查通过。
