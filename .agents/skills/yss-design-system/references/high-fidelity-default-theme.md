# 新项目后台高保真：默认主题起点

## 语义角色与颜色

| 角色 | 示例 | 用途 |
|---|---|---|
| 品牌强调 | `#3371ff` | 品牌标记与装饰，不能直接保证文字可读 |
| 可读操作 | `#245cd7` | 白底链接或白字主按钮的参考起点 |
| 页面 / 表面 | `#f0f2f5` / `#ffffff` | 页面底色与卡片、弹层、输入表面 |
| 主要 / 次要文字 | `#262626` / `#595959` | 实际背景需单独核验 |
| 选中背景 / 文字 | `#edf3ff` / `#245cd7` | 结合文字或标记表达当前状态 |
| 容器 / 输入边框 | `#e8e8e8` / `#d9d9d9` | 分别表达容器与控件边界 |

示例值可按设计替换或映射为目标框架的变量；不自动写入项目 Token。白色与 `#3371ff` 约 4.25:1，普通文字不能仅凭该组合声称满足 4.5:1；白色与 `#245cd7` 约 5.85:1，`#edf3ff` 与 `#245cd7` 约 5.26:1。按实际背景、字号、悬停、禁用和焦点状态检查适用对比度；单个配色不证明整页符合无障碍标准。链接和状态不只依赖颜色，必要状态配文字、图标或形状。

## 字体与密度

系统 sans-serif 为起点。正文、表格与表单约 14px / 22px，页面标题约 20px、区块标题约 16px。桌面间距参考 8 / 12 / 16px，页面边距约 12–16px、卡片内边距约 12–14px，卡片间距约 10–12px；卡片圆角约 8px、输入和按钮约 6px；常用控件视觉高度约 32px、侧栏菜单项约 40px。

内容、设备、用户需求和实际组件可改变这些值；不靠缩小正文或压缩必要反馈制造密度。视觉高度不等于可点击范围，也不等于已完成键盘、焦点或辅助技术检查。[页面组合](page-composition.md)按任务选择门户、工作台、列表和表单模式；简单页面无需套用完整门户。
