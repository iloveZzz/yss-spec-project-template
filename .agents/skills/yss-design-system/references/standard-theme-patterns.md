# 标准主题：列表与阶段看板

使用 [默认 DESIGN.md](../assets/DESIGN.md) 的角色。本文说明组合方式；业务字段、权限、日期语义与阶段流转来自当前 Spec。无基线的企业后台默认采用，有实际规范的项目按其约定覆盖。参考页面的布局和视觉已合并，客户名称、私有链接与业务分类不随技能分发。

## 公共结构

普通工作台沿用 `Workspace.vue` 的 240px 侧栏、52px 顶栏与流式内容。复杂信息结构可组合 60px 应用栏、104px 模块导航和130px 保存视图栏；这些是可选尺寸角色，不直接叠加在通用 Workspace 上。小于 1200px 折叠次要导航，小于 720px 使用已有 Sheet，不把导航挤进筛选区。

在基础样式和主题映射之后按需导入 `assets/vue-business-patterns/patterns.css` 与 `business-controls.css`。`.list-surface` 提供 12px × 20px 内容留白，窄屏 12px；`.list-toolbar` 最小高 46px 且可换行；`.list-filter-grid` 按最小 360px 参考列宽与容器空间重排，列间距 20px、行间距 10px；`.list-filter-field` 将桌面标签与控件横向排列，标签列最小 70px、参考占列宽 22.5%、间距 10px，窄屏改为标签在上。查询/重置使用 `.list-filter-actions` 放在网格最后一列并右对齐，窄屏允许按钮换行，不让最小列宽扩散为整页横滚。列表结果、筛选、分页在正常文档流内，二维滚动只限表格或看板。

## 组件组合与状态

批量动作复用现有工具栏，未选择时可禁用；不在选中后插入新的“已选 N 项”栏推动表格或分页。摘要需要时留在已有工具区，说明当前页/跨页、翻页、清空和重置语义。全选/半选按可选集合计算，禁用项不得进入批量操作；显示全部候选不扩大可操作权限。

| 模式 | 现有组件与样式 | 状态与内容约束 |
|---|---|---|
| 搜索 | `Label` + `InputGroup` + `InputGroupAddon` + `InputGroupInput` + Lucide `Search` | 图标 16px；外容器只有一层边框；输入保留独立名称、清空与无结果反馈 |
| 普通下拉 | `Select` / `SelectTrigger` / `SelectContent` / `SelectItem` | 触发器 32px，选项基础 32px、长项增高；选中蓝字 + 勾选，当前项灰底，键盘当前项细内嵌线 |
| 组合筛选 | `.compound-field` 包含标准控件、`TeamPicker` 触发器或 `DateRange embedded` | Select 的无 DOM 根组件可放在组内；每个触发器独立命名；边界重合 1px，只有外侧圆角；窄屏分行恢复完整圆角 |
| 页内分类 | `Tabs` + `TabsList` + `TabsTrigger` + `TabsContent` | 标签间距 24px、32px 点击高度、蓝字与 2px 底线；键盘方向键与焦点可见；只在 TabsList 内横滚 |
| 视图切换 | 同一 `Tabs` 组合，为 `TabsList` 添加 `.view-switch` | 相邻分段共享外边界，激活蓝底白字，移除页签底线；筛选和排序保存在父级，不能切换时重新初始化 |
| 日期范围 | `DateRange.vue` 的双输入 + `Popover` + 固定 RangeCalendar 原语 | 默认宽屏双月、窄屏单月；最近 7/30/90 天按固定参考日计算；确认才应用 |
| 跟进团队 | 范围 `Select` + `TeamPicker.vue` | 搜索、部门展开、多选/半选、已选列表、移除、清空与确认/取消；候选范围由父页提供 |
| 阶段看板 | `.stage-board` > `.stage-column` > `.stage-heading` / 内容 | 列最小 290px、间距 12px、0 圆角；仅看板横滚；标题文字和计数不由阶段色代替 |
| 空阶段 | `.stage-empty` + Lucide 图标 + 可读说明 | 最小 200px，内容可增高；使用当前筛选解释空态，不能假装加载失败是无数据 |
| 详情 / 确认 | `Sheet` / `AlertDialog` 或 `Dialog` | 右侧抽屉常用 520px，确认弹窗可选 416px；保留焦点陷阱、关闭、Escape 与返回触发器 |

弹层的 `as-child` 会替换按钮的 `data-slot`；触发按钮显式传 `variant`，主题按保留的 `data-variant` 映射样式，不能只靠 `[data-slot="button"]`。

组合筛选使用正常组件，不另包一套 Select 状态机。跟进团队将范围 `Select` 与 `TeamPicker` 放进有组名称的 `div.compound-field`，范围触发器添加 `.filter-operator` 并提供 `aria-label="团队范围"`，选择器传 `id` 和 `label`。日期条件将范围 `Select` 与 `DateRange embedded` 并排；组名称不能代替子控件名称。内部控件的错误边框优先于蓝色焦点，禁用与只读含义保持不同。

## 日期区间尺寸

`DateRange.vue` 保留 `{start,end}` 字符串模型与固定 `referenceDate`，默认显示可编辑的开始/结束输入和 Lucide 日历图标。传 `embedded` 时隐藏重复标签，作为组合筛选的后段；普通表单仍显示自身 Label。外部比较条件由父页提供，本地预览采用“介于 / 不限”，不推导业务 API 的比较运算。

宽屏浮层 662px（快捷区 102px、两个月份各 280px），窄屏实际只渲染一个月、宽度 304px并受视口限制，快捷项移到上方。内部复用锁定版本的 `RangeCalendarRoot` 与现有 shadcn-vue 日期子组件，独立呈现各月标题，保留键盘日期导航；不修改 vendor。日期输入下方向键进入日历，图标打开时将焦点送到当前可选日期。

最近 7/30/90 天均包含场景 `referenceDate`；例如参考日 `2026-11-03` 的最近 7 天为 `2026-10-28…2026-11-03`。键入、日历点选和快捷选择共用草稿，确认才提交；取消/Escape 回到已应用范围。两端为空表示不限，同日合法；单端、非法日期和逆序阻止确认并定位字段。日历规范化不能改写用户键入的非法/逆序原文，也不能自动把逆序范围修正为另一项查询。

月份按七列排布，日期点击格常规 36px，端点可见圆形为24px，选中区间浅蓝，端点蓝底白字。触摸时优先扩大目标至44px高；极窄屏七列的横向目标按可用宽度均分，至少满足24px，不能为了凑44px让页面溢出。月切换、快捷项、应用/取消可换行，长月份名称不截断。开始/结束输入当前焦点可使用 `surface-editing`，边框仍仅一层。

## 团队选择器

`TeamPicker.vue` 接收 `id`、`label`、`modelValue: string[]`、`departments` 和可选 `disabled`。部门形状为 `{id,name,employees:[{id,name,enabled}]}`；正式值为员工 ID 数组，名称只用于显示。本地样例覆盖“部门 → 员工”两级，不宣称提供任意深度组织树、远程检索或真实权限服务。

桌面浮层宽 680px，主体基准 320px 高，左右分别为候选与已选；底部固定显示“显示所有员工”、取消和确定。窄屏上下排列，两区分别限制高度，整体受浮层可用高度约束，底部操作保持可达。默认只显示 `enabled` 员工，勾选“显示所有员工”扩大当前候选的显示范围，不扩大父页传入的数据权限。

部门勾选只作用于**当前显示**的成员；筛选或隐藏候选不清空已选，部分选择显示半选。搜索同时匹配部门、姓名和编号；右侧显示已选总数、部门与编号，可逐项移除或清空；关闭后的触发器名称包含已选摘要。上述操作先改草稿，确定才提交，取消/Escape 不改原值；失效 ID 阻止确认并要求移除或重新选择。切换外层范围后的候选与权限由调用页确定，选择器不静默丢弃原 ID。

日期与团队弹层沿用 Popover 的焦点管理：确认、取消和 Escape 返回触发器；点击或 Tab 到外部控件时保留新的焦点，不用无条件回焦点覆盖外部操作。

## 看板与数据表

`.stage-column` 的 `data-stage="new" / "won" / "lost"` 选择 `stage-new / won / lost` 色；新业务通过局部 `--stage-accent` 引用已登记的角色，不直接改全局成功/错误色。`.stage-heading` 内使用 `h3` 显示阶段名，可用 `small` 放计数，顶部短色条不承担唯一状态说明。滚动看板需有可访问名称、可键盘进入的滚动容器和可见滚动提示。

来源页面用于提炼容器与状态，不据此生成机会卡片字段、拖拽、阶段权限或自动转移；来源旧报告不是本次验证结果。项目有数据后按其真实任务设计卡片。切换列表后复用同一结果集；表头与新标准数据行基础均为48px，表格正文14/22，并随多行文本、标签和按钮增高。`.list-surface` 内可移除外框与行 hover 底色，保留选中态、行内操作反馈和键盘焦点；不影响其他表格。固定首列的表头维持表头底色，不能被数据单元格白底覆盖。

## 适用边界与核对

可选导航、搜索顶栏与头像在线标记按实际信息结构组合，尺寸使用 CSS px，不从高分屏截图反推。头像使用有来源的项目素材或已有图标/文字；不把 SCRM 的业务快捷动作、素材路径或局部弹窗尺寸写成通用规则。

主色、文字、背景、圆角、表头与浮层属于公共主题；三级导航、组合筛选、日期快捷项、分段视图和看板属于按需组合。保留原有反馈语义色，阶段色只描述业务阶段。Hover / Active 和必要边框的对比度优化属于设计决定，不声称是参考站点原始值。

按本次使用范围核对：按钮无原生立体边框或阴影；搜索和下拉图标尺寸与对齐；单层输入焦点与错误优先级；选中项和键盘当前项分离；页签/视图切换不丢筛选；浮层可关闭且焦点返回；窄屏只在需要的二维内容里滚动。计算样式与构建通过不等于人工读屏、真实数据卡片或生产组件库验证。
