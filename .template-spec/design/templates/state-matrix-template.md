# <功能名称> 状态矩阵

> 按需要由产品设计或逻辑原型消费，分别记录业务状态与界面状态及其规则对应；可并入现有说明，不要求额外文件。

业务状态描述业务对象的生命周期；界面状态描述展示、请求和交互反馈，两者通过同一业务规则关联。按当前任务与风险选择相关状态和转换：例如提交请求失败时，业务可能仍为草稿，界面显示提交失败，实际结果以 Spec 为准。

页面状态表和转换表按需选用，不要求穷举 loading、empty、error、readonly、disabled、no-permission、conflict 等所有界面状态，也不为未命中项逐项填表。已有权威状态规则时直接引用；关键转换的触发、前提、结果或恢复未知时列为待确认，不补造状态机。
