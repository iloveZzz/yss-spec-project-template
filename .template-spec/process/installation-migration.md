# 安装方式与显式迁移

新安装合同提供 `skills` 和 `governed` 两种安装选择。新建和接管缺省 governed，安装现有生命周期政策；仅需独立技能和工程入口时显式选择 `--installation skills`。选择保存在受管安装元数据，不要求普通任务填写模式或资格字段。Profile 仍为 Spec/Backend。

普通同步保持原选择；没有新字段的旧 metadata3/4 按原正式合同解释，不能按新建默认值转换。当前转换只接受可核验 metadata4/5；metadata3 先使用已有显式治理迁移。

显式安装转换复用 CLI migrate 的 plan/apply。计划列出将修改的受管入口、来源和安装选择，保留任务、checkpoint、批准、历史政策及用户文件。存在活动任务或无法核验完成状态的正式绑定时拒绝转换。首版不自动处置任务包，不把删除绑定或修改状态当成完成。

规划及应用绑定当前入口、元数据、tracker.root 与工作目录集合。规划后新增、删除或修改工作资产需重新规划；事务写入后再检查观察集合，不符时不得报告成功。回滚遵循原事务的覆盖冲突保护，不重置用户后续工作。

完整产品阶段记录仅由正式治理入口解释；普通技能调用不产生批准。源码构建与测试不代表发行验收。具体命令与支持版本以所用 CLI 帮助为准。
