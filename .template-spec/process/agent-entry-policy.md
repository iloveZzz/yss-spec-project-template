# 按任务开展工作

根 AGENTS.md 定义共同边界。直接消费当前需求、代码、业务词汇和相关技术资料，不加载生命周期资格、门禁注册表或测试证据协议。

Spec 完整交付只包含业务规格、高保真交互原型及交互说明；纯展示可用高保真静态稿，无 UI 用逻辑/状态原型。业务票仅按明确拆票请求组织，不自动生成技术设计或实现 Slice。普通查询和局部修订只完成当前范围。

免除流程审批不扩大任务范围。用户明确要求技术设计或开发时作为研发任务按授权与可用能力承接，不以 Spec profile 拒绝；研发依据实际工程与设计细化实现 Slice。已有 Ticket、PR 或文档可继续使用，没有则不为流程补建。

生成与整理由 Agent 直接使用保留的模板和资产完成。安装、同步和发行若使用现有 CLI，先查看该版本实际支持的命令；工具自身失败如实报告，不伪造成功。

测试、审查和验证按用户要求与任务需要选择，不形成统一门禁。报告实际完成内容和未覆盖范围。用户文件保护及对外操作授权见根 AGENTS.md。
