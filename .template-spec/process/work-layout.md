# 工作资料布局

沿用工程已有目录与明确配置。业务材料放在用户指定工程，模板源仓只维护分发资料；稳定说明与成果入口可放 `docs/`，适用模板资料位于 `.template-spec/`，CLI 安装与事务状态位于 `.yss/`。按需创建资料，不为开工补建功能包、阶段目录或资格记录。

既有业务资料和配置在同步时保留；不因看到目录就猜测新的资料根，也不批量移动历史材料。用户要求整理时，先读取引用与实际内容，在授权范围内修改并修复受影响引用。未知外部引用或冲突应保留并报告。

CLI 不提供历史工作包布局迁移或阶段合同命令。受管安装更新使用 `sync`，用 `--dry-run` 预览；中断后按实际 `doctor` / `recover` 帮助处理，不删除恢复材料掩盖问题。
