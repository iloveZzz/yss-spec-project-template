# 业务输入

> 全部为虚构输入，仅用于模板和诊断验证；不是产品事实或批准。

| ID | 原始规则 |
|---|---|
| S1 | 经办人点击提交时检查本单据要求的附件清单。 |
| S2 | 缺少任一必需附件时拒绝提交，单据仍为草稿。 |
| S3 | 一次列出全部缺失附件名称。 |
| S4 | 保留当前页面已填数据；不承诺刷新或关闭后的恢复。 |
| S5 | 补齐后重新点击提交，重新执行校验。 |
| S6 | 全部必需附件齐全且其他提交条件满足时，沿既有提交流程。 |
| S7 | 本期不校验附件内容真实性，不处理刷新恢复。 |
| S8 | 附件清单读取失败时的行为未知，需在 Spec 冻结前确认。 |
