# 用户手册索引

## 第一次使用

1. [YSS 用户手册](用户手册.md)：四个现行家族的选型、CLI、确认、同步和恢复。
2. [设备借用贯穿案例](设备借用贯穿案例.md)：战略、后端、前端与统一验收的完整练习。
3. [技术设计用户指南](技术设计用户指南.md)：批准战略或 Spec 如何进入 DDD / layered-mvc 技术设计和实现合同。
4. [阶段接入与产物复用使用手册](阶段接入与产物复用使用手册.md)：从已有产物继续，含后端交付后前端接收、准备、开发及恢复步骤。

## 按本次目标继续

- [先完成 Spec，再继续设计与交付](用户手册.md#先完成-spec再继续设计与交付)：五个终点、可复制 Agent 指令与同一功能续推。
- [本地主控与独立专职接力](用户手册.md#在一个主控内完成还是交给专职工程)：消费者绑定、交接和前端依赖。
- [完成结论怎么看](用户手册.md#怎样看完成结论)：本次目标、本端职责、整体业务与等待原因。
- [目标配置命令](unified-cli.md#正式功能的可续推目标)：JSON 输入、计划、应用、只读状态与恢复。
