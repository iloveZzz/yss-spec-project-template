# 技能投影与锁定

技能投影是从权威共享技能生成、供特定 Agent root 加载的同步副本。`.agents/skills` 是跨 Agent 共享技能的权威内容；`.claude/skills`、`.codex/skills`、`.hermes/skills`、`.pi/skills`、`.qoder/skills`、`.trae/skills` 中的共享技能是生成投影，禁止分别手工修改。

技能清单、来源、版本、哈希和投影目标登记在 `skills-lock.json`（机器可读锁文件）与 `yss-public-skills.json` 中。模板维护流程要求：修改技能或流程规则后，运行 `scripts/sync-skills` 同步投影、`scripts/update-skill-lock` 更新锁文件，再执行 `scripts/verify-template` 压力验证（见 [[模板维护流程]] 与 [[模板发布门禁与验证]]）。

`scripts/export-yss-skills` 负责导出 YSS 技能集，`scripts/verify-yss-ui-scenarios`、`scripts/verify-lifecycle-scenarios`、`scripts/verify-yss-router-scenarios`、`scripts/verify-matt-yss-integration-scenarios` 等分别验证技能投影与流程语义在压力场景下的正确性。投影与锁文件的哈希一致性是模板发布门禁的组成部分。

技能治理规则：新流程统一使用 Spec、Ticket、`to-spec`、`to-tickets`；过时术语与旧技能名只能出现在迁移指南或明确标注的旧项目上下文中。
