# 产品设计影响与原型

产品设计影响指 UI 变化触及主流程、导航、权限体验、异常 / 恢复状态、状态流转或 API 反推时构成的设计工作，强制产出页面流（低保真草图）、状态矩阵、Ant Design v6 高保真 HTML 原型和用户确认。

判定规则：只有上述影响才构成产品设计影响并强制完整流程；文案、token、颜色、间距和无行为变化的孤立视觉修复属于 UI 影响，但不自动构成产品设计影响，记录 `not-applicable`（见 [[影响面分诊与流程裁剪]]）。

流程：低保真原型（wireframe / Excalidraw / 页面草图）→ 原型评审（对照状态矩阵与交互说明）→ 通过后进入 Ant Design v6 高保真 HTML 原型 → 用户确认 → 反馈 Spec 校准与 OpenAPI Draft（见 [[Spec基线]] 与 [[OpenAPI契约]]）。高保真 HTML 原型用于在浏览器中审查真实视觉密度、交互状态和页面流，不等同于生产前端实现。

UI 设计、原型与主题实现由 `yss-design-system` 技能提供 Ant Design v6 事实，产出前用 `antd` 查询设计系统事实；原型评审使用 `prototype-review`，高保真原型使用 `high-fidelity-html-prototype`（见 [[YSS工程技能体系]] 与 [[Matt技能体系]]）。
