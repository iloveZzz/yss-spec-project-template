# YSS Spec Project Template 总览

YSS Spec Project Template 是一个基于 Matt Pocock Engineering Skills、YSS 与 OpenAPI 驱动的轻量 AI 研发文档模板。它默认作为 Harness / 研发管理仓库，承载流程文档、契约模板、Agent skills 与协作约定；前端与后端源码默认位于独立实现仓库（见 [[实现仓库与跨仓库契约]]），仅在用户明确选择时才在本仓库按需创建 `apps/` 目录。

模板的核心目录包括：`.agents/skills`（跨 Agent 共享技能权威内容）、`docs/`（按生命周期划分的文档资产，含 adr、api、requirements、design、architecture、agents、templates、process 等子目录）、`scripts/`（模板轻量校验脚本）以及根级权威资产 `AGENTS.md`、`CONTEXT.md` 与 `yss-project.yaml`。

Quickstart 要求：先读取 `yss-project.yaml` 按 `repository_mode` 选择流程（见 [[仓库身份与路由]]）；必读入口为 `AGENTS.md` 与 `CONTEXT.md`；`template-source` 模式走 [[模板维护流程]] 流程，`project-instance` 模式进入 [[产品研发生命周期]] 产品研发生命周期。

本模板强调单一事实来源：领域词汇以 `CONTEXT.md` 为准，流程事实以生命周期映射与裁剪指南为准，技能清单以 `skills-lock.json` 为准（见 [[技能投影与锁定]]）。
