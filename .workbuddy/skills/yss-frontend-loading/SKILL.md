# YSS 前端加载与过渡

适用于需要决定等待期间显示哪些内容、保留哪些操作，以及结果如何切换或恢复的实现与审查。先读有关规格、目标页面、路由和已有请求状态。页面工程与设计一致性由 `yss-frontend-application` 衔接，组件选型由 `shadcn-vue` 衔接。沿用目标工程的授权、组件源码和请求层。只读审查交付可复现的发现。

## 从原型接到工程

接续高保真原型时，从 Spec、交互说明和已有 `prototype-review` 结论定位已确认的反馈区域、可保留内容、可用操作和失败后的恢复。按目标工程的路由、权限、实际请求状态和服务端回执实现这些行为，复用本地组件、主题和可访问性约定。

原型用来演示状态的计时器、手动切换器或固定成功响应留在模拟边界。为本次真实路径补齐适用的快速响应、慢请求、空结果、权限失效、失败、取消及重试等状态。依赖真实数据且接口尚未提供时，用隔离的请求模拟覆盖相关状态，并标记待联调。

例如，原型通过定时器呈现表格换页。工程由真实请求决定 Spinner 的显示范围和结束时机，保留已授权的旧行，保护与旧结果绑定的动作，由最新有效响应更新表格，并验证失败后的重试目标和焦点。

## 按等待的对象选择反馈

| 场景 | 呈现与交互 |
| --- | --- |
| 冷启动、深链接 | 先显示最小静态启动反馈或安全框架。会话与目标授权就绪后进入业务内容。入口资源、会话及区域读取分别反馈失败与恢复。静态启动反馈在应用接管后清理。 |
| 应用内切页、异步弹层 | 导航获准且目标框架可用前保留当前页和输入，慢导航在导航区提示。弹层先挂载有标题、关闭与焦点管理的外壳，正文独立等待；关闭、离页或回退后，旧结果失效。预取只覆盖允许提前读取的资源。 |
| 首次读取、复杂页面 | 在没有可展示结果的区域预留结构，慢请求显示与最终表头、行高、卡片、图表或字段布局相近的 Skeleton。主档、指标和次要区块依各自数据与权限就绪，区块失败在原位恢复。真正共享前置条件的操作等条件齐备再开放。 |
| 表格筛选、排序、分页、刷新 | 有可保留的旧行时，保留表头和滚动位置，在表格可视滚动区域轻量覆盖并显示居中的 Spinner。筛选区可继续输入。换条件或翻页时，标明旧结果并暂停与旧结果绑定的行和批量动作。无法安全保留旧数据时，清空并回到区块预留状态。 |
| 移动刷新、追加和远程选项 | 刷新在列表头反馈，追加在列表尾反馈，保留已有条目和阅读位置。提供可操作的刷新或追加入口。远程搜索与级联候选在其区域等待，移除已失效候选，保留仍有效的输入。 |
| 保存、上传、导入、导出 | 接受动作时立即阻止重复和冲突操作，慢等待用局部 Spinner 搭配动词文案。按真实来源显示上传或任务进度；未知进度只表达正在处理。区分已受理、已确认成功、部分成功、确认失败和结果未知。 |

## 维护状态与数据一致性

- **显示结果与最新意图。** 用同一成功快照读行、总数、页码及已生效条件。待请求条件与重试目标单独保留。成功空结果有自己的状态，失败、无权限、未开始都有适用反馈；换条件失败后明确旧结果的归属，并继续保护其依赖动作。同条件刷新保留仍有效的选择，权限或对象发生变化时立即清除不再可见的数据和选择，覆盖缓存、回退和组件复用路径。
- **请求竞争。** 对读取和导航，以最新的会话、授权范围、路由或对象、查询和请求身份校验响应。复用原状态所有者，能取消就取消，并在提交状态前拒收失效的结果，包含 `finally`、计时器和加载更多回调。失败重试沿用正确的目标；取消结束当前反馈并清理资源，取消的刷新不播报成功。
- **写入回执归属。** 发起时记录会话、对象和操作身份，在应用成功、失败及清理状态前校验归属。离开页面可结束客户端等待，服务端结果仍需核对。原会话仍有效且权限仍允许时，晚到回执可用于更新所属对象或任务。后来打开的表单、草稿和新操作的等待状态由各自的操作维护。
- **写入与回读。** 从服务端结果确认写入。已确认写入后的读取失败保留写入结论，并提供读侧恢复。明确失败保留允许保留的草稿、文件或选择。退出等待、超时或断网后若结果未知，先按已有业务契约核对状态、任务或幂等标识，再决定能否重试原写入。
- **追加与恢复。** 按查询范围给追加和刷新定身份。结果合并按稳定标识去重，维护已有追加页或游标及可继续读取的位置。刷新时按实际 API 决定如何校验已见条目；条件变更后清除旧范围的页和迟到追加结果。

## 组件与动效边界

- 复用项目已装的 shadcn-vue `Skeleton`、`Spinner` 和 `Button`。原语管样式与基础语义；反馈组件管文案、可访问播报与动效；页面或现有 composable 管数据是否可用、等待范围、权限和重试。抽取多处公用的反馈，保留各场景的布局与业务动作。CSS 遮罩的 `pointer-events` 只影响指针，禁用行操作要覆盖键盘和处理函数。
- 请求开始就生效的保护与延迟出现的视觉反馈分别处理。按实际请求分布与设计选择展示延迟，短请求直接交付结果；状态解决后立即收起提示。为长等待保留静态、可读的状态与恢复入口。延迟展示、停止动效和网络超时各有独立语义。
- 让位移和布局保持稳定，优先短淡入或低幅动效，遵从 `prefers-reduced-motion`。用 Vue `<Transition>` 处理有价值的进出场，避免为插槽或行列表重挂载输入与焦点。Vue Router 动态导入有自己的导航生命周期；Vue `<Suspense>` 面向受支持的异步组件依赖，给它补上独立的失败恢复。缓存页面时核对返回、失活和授权变化。
- 装饰骨架与重复 Spinner 对辅助技术隐藏。为对应区域设 `aria-busy`，需要播报等待时提供一个简短、稳定的 `role="status"`，避免放在会推迟该播报的 busy 容器内。保留语义、键盘路径和取消入口。减少动效、深色及强制颜色下，等待、失败与重试依旧可辨认。
- 计划等待结束后的焦点去向。若结果替换移除了当前聚焦的重试控件，将焦点放到结果区域、区块标题或仍可用的入口。关闭弹层后返回有效的触发控件或其替代入口。成功切页沿用项目的路由焦点策略。局部异步更新期间保留仍有效的焦点。

## 验证发生变化的路径

按本次范围选取可观察分支。用可控快速、慢速、并发逆序、空响应、失败和无权限请求检验结果与控件是否同步。补看换条件失败后重试、切页取消、重复提交、写入成功回读失败，以及移动列表刷新后的阅读位置。保存 A 后切到 B，或切换身份后再让原回执到达，检查当前内容、草稿和待处理状态。路由资源恢复在生产构建中模拟必要的 JS/CSS 失败，点重试并验证资源重新获取及内容恢复。用键盘操作重试和关闭弹层，检查原焦点节点撤下后的落点。结合窄视口、减少动态效果及适用的辅助技术检查交互，按实际证据报告浏览器模拟、真机和真实服务联调。

[SCRM 双端案例与回归证据](references/scrm-case-study.md)用于分析过渡方案或定位同类问题。组件与平台依据见 [Skeleton](https://www.shadcn-vue.com/docs/components/skeleton)、[Spinner](https://www.shadcn-vue.com/docs/components/spinner)、[Vue Transition](https://vuejs.org/guide/built-ins/transition.html)、[Vue Suspense](https://vuejs.org/guide/built-ins/suspense.html)、[Vue Router 动态路由加载](https://router.vuejs.org/guide/advanced/lazy-loading.html)、[WAI-ARIA aria-busy](https://www.w3.org/TR/wai-aria-1.2/#aria-busy)和 [W3C 减少动态效果技法](https://www.w3.org/WAI/WCAG22/Techniques/css/C39)。
