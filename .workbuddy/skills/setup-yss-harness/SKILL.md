# 安装与同步 YSS

先区分安装程序、安装技能、同步工程或生成骨架，复用当前路径和已有授权。先读已安装的 `yss version`、`yss help` 和目标命令帮助；模板更新不改变旧二进制支持范围。本文描述的新精简接口尚未正式发行，不把旧发行版称为支持新接口。

首次安装由 Agent 完成：依据官方发行说明选择用户授权版本和本机平台，确认实际归档名称、SHA-256 与来源，在临时目录安全展开并核对程序帮助，再安装到独立工具目录、配置 PATH。未找到正式发行时报告缺口；未经授权不把开发构建当正式版。没有 CLI 时也可直接在授权技能目录安装所需技能源及资源，保留来源、许可证和用户文件。

新接口只使用以下命令：

- `init`、`attach`、`sync`：新建、接管与同步；`--profile spec|backend`，`--installation project|skills`。安装方式转换使用 `sync --help` 列出的开关。
- `skills list`、`skills ensure`：查询或补装技能及所需资源。
- `scaffold catalog`、`scaffold ddd`、`scaffold mvc`：查询平台并生成全新骨架；保留明确的项目、平台与 Maven 坐标输入，不需要合同或资格，不生成测试门禁，不自动执行 Maven。
- `upgrade --to <版本> --tool-root <目录>`：在线升级；离线改用 `--artifact <归档> --sha256 <摘要>`，不混用来源。
- `doctor`、`recover`、`version`、`help`：诊断、恢复与查询。

写入默认直接执行，同一操作加 `--dry-run` 仅预览，不创建目标、控制目录或保存计划。恢复参数以实际帮助为准。旧插件、旧兼容入口、保存计划及 plan/apply 流程不属于新接口。已有旧 CLI 只按它自己的帮助操作；需要新能力时先确认可安装版本，不能编造兼容命令。

已有工程先读内容和受管状态，只改授权范围；保留路径、符号链接、覆盖、摘要和子模块保护。冲突或中断保留现场，使用实际支持的诊断恢复入口。不得删状态、改身份或覆盖用户工作伪造成功。不注入脚本、测试套件、阶段门禁、批准包或资格记录。报告实际版本、来源、修改与未完成事项。
