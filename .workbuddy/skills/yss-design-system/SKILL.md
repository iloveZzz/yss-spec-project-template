# Spec 设计规范

适用于非技术产品设计中的视觉与交互一致性问题，使用 [按需设计规范](references/spec-design.md)。读取已有根 DESIGN.md 与实际相关 Token；缺规范时说明缺口，在授权范围提出最小设计依据，不虚构已有规范或批准。

life / yss-prototype-stage 决定需要什么表达，本技能不要求先做低保真、选择 H1/H2 或制作可交互原型。不要求 OpenAPI、端点、实现切片、生产组件或技术合同，也不强制全部主题和六轴 QA。

只对当前产物及声称的范围检查。静态视觉不证明交互，原型操作未执行不写通过；复杂状态或业务规则交回产品设计与 Spec，不通过视觉润色替用户决定。

返回使用的规范来源、实际调整或检查、允许差异与未解决问题，不自行批准、冻结或授予实施资格。历史参考中的实现/档位流程不作为新 Spec 的前提。
