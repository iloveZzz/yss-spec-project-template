# YSS Tesla Light：默认采用与项目覆盖

无既有设计基线的企业后台默认采用本主题。完整规范与机器可读 Token 见 [默认 DESIGN.md](../assets/DESIGN.md)，已有项目沿用实际规范；明确要求迁移时只替换本次授权的规范与页面。

| 角色 | 默认 |
|---|---|
| 品牌与操作 | `#3E6AE1`，Hover `#345BCC`，Active `#2B4EC5`；主按钮白字 |
| 浅选中背景 | `#E2E9FB`，主蓝 15% 混合白色；使用文字、勾选或指示线同时表达状态 |
| 正文 / 辅助 | `#171A20` / `#5C5E62`；placeholder 使用可读辅助色 |
| 画布 / 面板 / 导航 | `#F4F4F4` / 白色 / 白色 |
| 边框 | 装饰 `#E4E4E7`，必要控件边界 `#86888D`；错误边界使用语义错误色 |
| 排版 | 正文 14/22，标题 20/30/600，表头 14/22/400，辅助 12/18 |
| 应用壳 | 全宽顶导 56px、业务侧栏 224px / 折叠 64px、已开页面标签栏 40px |
| 布局 | 品牌左、主模块居中、用户工具右；白侧栏承载当前模块业务菜单；内容使用浅灰画布上的白面板 |
| 控件 / 表格 | 默认 small / compact 控件 28px、表头和数据行基础 40px且可增高；medium / comfortable 显式使用 36px |
| 圆角 | 控件 8px、Checkbox 方框 3px、卡片与弹层 12px；看板列 0；普通卡片与按钮无阴影 |
| 触摸 / 焦点 | 常用目标优先 44×44px；输入单层主色边框，其他键盘目标保留清晰轮廓 |
| 留白 | 页面 / Card 16px，宽松 Card 20px，窄屏 12px；不靠缩小文字制造密度 |
| 字体 / 图标 | 系统中文 sans-serif 回退与 Lucide SVG；未获授权的 Universal Sans 不是运行依赖 |

Tesla preset 是色彩与极简气质参考，HeroUI 是层次、细边框与圆角参考；不复制品牌标识、汽车素材或 React 库。保留 Vue + shadcn-vue。顶导与侧栏按实际内容收纳，保存视图栏只在业务需要时增加，不默认叠加旧多轨侧栏。

顶部一级模块与左侧二级业务菜单联动，已开页面跨模块保留。工作台固定保留，其余页签提供独立关闭按钮。激活页签同步顶部模块和左侧当前项，关闭非当前页保留当前页面，含未提交修改的页面经草稿守护后关闭，取消保留输入，当前页关闭后激活相邻页。详细语义见 [标准页面模式](standard-theme-patterns.md)。

桌面标签栏高 40px，窄屏或粗指针采用 44px 标签与关闭按钮命中区域，栏高随内容自然增高。

主题定义值、页面引用语义角色，CSS 覆盖 Teleport 弹层；组件默认、悬停、按下、禁用、焦点、选中与错误状态均需可辨识。保留成功/警告/错误语义色，不把业务阶段色等同反馈。对比度按真实相邻颜色核验，不以浅装饰边框承担必要控件识别。

主题装配见 [主题映射](prototype-default-theme.md)，组件来源见 [Vue 原型](shadcn-vue-prototype.md)，列表与筛选见 [标准页面模式](standard-theme-patterns.md)。默认只支持亮色；已有项目、暗色及历史 compact 快照不自动迁移。修改模板默认时同步所采用的规范、亮色变量与角色映射；不覆盖其他项目。
