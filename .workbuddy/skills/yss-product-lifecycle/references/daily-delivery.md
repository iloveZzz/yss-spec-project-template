# 按需交付

直接使用当前目标、已有规格和真实决定开展工作。续接先看已有修改与命令结果，不重放结果未知的外部动作。没有任务记录时可在当前对话说明范围和结果，不补建 Ticket、checkpoint 或批准包。

完整产品 Spec 按 [共享规格方法](spec-workflow.md) 交付业务规格、高保真交互原型及交互说明；纯展示和无 UI 使用对应形式。业务票仅在明确要求拆票时组织，不自动续写生产技术设计或实现切片。明确研发请求按授权承接，普通查询、局部修订只完成当前工作。缺真正业务选择才询问；其余已授权工作继续。

提交、推送、部署、发行和远程发布沿用对应授权。交付说明实际修改、实际执行结果、限制与未完成项，不用程序退出码或静态截图代替行为证据。
