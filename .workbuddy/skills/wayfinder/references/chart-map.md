# 建立地图

### Chart the map

1. 从用户目标与已有讨论确定 Destination；只澄清真正缺少的取舍，词汇方法按需使用。
2. 横向找出未决问题及依赖。已无重要未知时直接返回结论，不为使用技能创建地图或票。
3. 在当前对话给出结构；请求授权保存时复用目标 tracker/文件和现有地图。先查同一目标的已有记录，不能按同标题重复建。
4. 只为现在能准确提问的问题建票；无法提问的范围内未知保留为 fog。按 [地图格式](map-format.md) 在授权范围保存明确方法类型，沿用已有映射；新增真实 ID 取得后再建立关系，不支持原生关系才使用文本。缺少标签或写入权限时说明未保存部分，不自动创建标签或改 triage 分类。
5. 当前请求允许时继续独立事实调查或相关小决定，不设固定会话次数或任务包前置。没有子代理能力时顺序处理。

创建超时先查询结果，未知时保留未知而不重发；只读请求不创建。报告实际保存/发布状态与未决项，不把地图建立当实现完成。
