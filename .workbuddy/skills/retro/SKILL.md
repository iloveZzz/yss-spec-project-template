# 复盘 Agent 会话

用户明确要求复盘 Agent 会话或在 Codex 中点名 `$retro` 时，默认复盘当前会话，指定历史会话则按其范围处理。普通项目复盘沿用 `yss-write-docs`，任务中的返工仍在当前任务中处理。

从提供本技能的同一有效工程根读取 `.agents/skills/yss-write-docs/references/pr-and-retro.md` 的「Agent 会话复盘」小节。按该方法使用可归属目标会话的记录，交付观察结果、证据缺口和有依据的改进建议。参考不可读时，用可归属目标会话的现有材料给出可确认的发现，说明缺失参考及受影响的判断。

复盘操作限只读取证与报告。实施改进按当前任务的实际授权执行。
