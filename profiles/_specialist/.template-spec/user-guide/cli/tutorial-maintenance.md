# 维护与恢复

命令支持以所装版本帮助为准。先运行 `yss version` 和 `yss help`，仅使用该版本实际支持的命令；模板更新不改变旧二进制能力，也不代表当前程序是最新发行。

维护已有工程使用 `sync`，补装技能使用 `skills ensure`，程序更新使用 `upgrade`。写入前可用 `--dry-run` 查看同一操作；不保存和应用计划。

同步只处理授权的受管内容；保留用户修改、子模块和未知文件。安装方式转换查看 `sync --help`。失败后使用 `doctor` 诊断，再按 `recover --help` 恢复未完成事务；不能通过删除备份或控制文件掩盖失败。

模板仓不分发脚本和测试套件。发行准备由 Agent 使用实际 Go 构建工具与标准归档工具完成，不重建门禁。
