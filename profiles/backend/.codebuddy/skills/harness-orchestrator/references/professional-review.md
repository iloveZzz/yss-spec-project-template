# 专业检查与恢复

当前 Profile3/policy2 按实际工作单元、影响面及适用 Skills 编译 task3。默认同一 Agent 完成专业工作与自检；不要求岗位、数字人、runtime 注册或固定 Agent 数。明确用户要求或已知外部规则需要独立复核时，核验真实不同上下文、相同冻结候选、实际只读执行轨迹及要求的真人决定。同账号可具备不同真实上下文，换名字或重读同一会话仍是自检。

`scripts/prepare-review-package` 接收当前任务事实和已完成工作的真实来源，只起草 pending task3/bundle3。当前批准由固定 CLI 核验当前消费者 checkpoint、原始主体/范围/依据、政策摘要及实际任务结果；不生成未来执行证据或真实用户回复。历史记录使用原政策，只读结果不授予新资格。

首轮覆盖所有适用检查，修复后依据实际差异、受影响结论、行为及依赖定向复核并重新绑定当前候选。未受影响项有可读比较依据才复用；未知影响先调查并阻断依赖。没有已知外部规则不要求填写空制度；已知但不可核验的要求仅阻断对应动作。验证未执行、非零退出、当前来源缺失或阻塞未清除均不能标为成功。
