# 增量摄取

处理用户点名或任务已授权的来源，搜索命中不自动等于摄取许可。先读现有索引、相关页面和来源，区分新增、更新、冲突与无实质变化。

已授权范围直接增量维护 Markdown，沿用当前目录和链接风格；只读请求仅给候选。无新信息时不改文件。必要快照仅在本次范围保存，标明来自外部或工作树，不伪造 live 路径。

更新前复读目标，发现并发变化先整合；无法安全区分时暂停受影响写入。人工正文的保护按 [写作方法](writing.md)；来源冲突保留双方证据，不能用新摘要掩盖旧事实。

代码结论注明仓库/commit；含未提交修改时注明文件、工作树状态及实际读取时间，不把它归给 HEAD。变动的偏好/决定记录确认日期与来源。外部快照未经在线回源不能称当前有效。

只改受影响文章及必要导航，在授权范围简要记录变更；标记被新事实替代的旧结论并保留来源。回读本次正文和链接，报告实际修改、冲突和未覆盖部分。无需脚本、schema、manifest、统一事务或固定数量门槛；已有历史基础设施不自动删除。
