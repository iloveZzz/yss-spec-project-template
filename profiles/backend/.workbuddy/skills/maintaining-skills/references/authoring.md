# Skill 编写

名称和描述说明独特触发场景与实际结果。正文保留必要输入、判断依据、技术边界和操作方法，细节放在按需参考中，不要求每次加载全部资料。

保留当前宿主支持的元数据、来源和许可证。显式调用与自动选择属于发现策略，不授予对外动作权限；不要因技能安装而假定已获提交或发布授权。

修改共享内容源后同步对应平台副本与清单。删除失效命令和重复流程，不新增脚本、测试套件、检查计划、审批或发布门禁。用可读的任务说明表达需要 Agent 完成的操作。

来源记录区分原始引入版本、比较版本和有效内容哈希；复用现有分发清单让适配说明随相关技能安装，不新增锁 schema。Backend 从共享源继承时保持来源信息，不能覆盖其专有内容或平台元数据。

跨技能按需读取方法时，声明相对项目根的 canonical 路径，并在适用安装模式的 skillReferences 中分发所需叶子资源；只读取参考不等于安装或调用整个技能。检查单项安装后的引用闭包，不能用全量预装掩盖缺失资源。结构核对不能替代实际宿主发现与行为观察。
