# Backend 工作编排

依据用户目标、现有需求和工程状态直接组织后端工作。按需要澄清业务、读取代码、设计方案、实现和交付；不使用生命周期路由、阶段门禁、合同编译或测试证据协议。

使用适用的 YSS 技能，沿用当前工程的 DDD 或 MVC 架构。任务拆分只说明目标、范围、依赖和实际结果，不创建形式化任务包、checkpoint 或就绪状态。

普通工作参考 [按需交付](references/daily-delivery.md)。测试、审查和构建按用户要求或实际需要进行，不是统一前置。保护用户文件，提交、推送、部署和发布沿用对应动作授权。
