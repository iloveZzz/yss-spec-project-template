# 后端规范审查与整改

按用户指定工程、范围及读写授权，阅读当前需求、实际代码和适用 YSS 技术说明。只审查时报告差距；明确要求修复时持续完成范围内整改。

按实际 DDD/MVC 架构检查层次职责、对象转换、数据访问、事务、API、输入校验和权限行为。规则依据当前工程和真实源码，不要求先注册工程、补批准合同、生成源码摘要或准备测试证据。

逐项报告具体文件、问题、影响与建议；修复同步真实调用方，不为了符合模板重建成熟工程。测试、构建和独立复核按用户要求或具体需要选择，不新增统一门禁。

最终说明覆盖范围、已改内容和未解决问题。提交、推送、发布与生产数据变更遵循各自授权。
