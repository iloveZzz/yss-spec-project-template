# 公开分发技能

将用户选定的技能发布到指定 GitHub 分发仓。先明确源、目标和公开范围，复用本次会话已有授权；只整理本地文件不等于授权推送。

由 Agent 直接复制选定技能及必要资源，保留许可证和运行时元数据，修正包内引用。YSS 清单与路径参考 [导出说明](references/yss-export.md)。不复制用户业务文件、凭据或本机私有路径。

沿用目标仓目录与命名，按本次选定范围同步 README、安装说明、分组及既有来源记录，保留未更新技能的真实来源和无关修改。完整白名单对齐与部分同步分别报告；停止分发旧入口只清理已确认的分发文件，不删除消费项目中的旧安装。使用已有 Git、连接器或 CLI 提交和推送；不要求导出脚本、摘要包、安装测试、CI 或独立审查作为发布前置。

报告实际提交、PR 或发布链接。只有实际观察后才声明安装或 skills.sh 收录成功；页面尚未更新时说明现状，不自动创建轮询任务或改变遥测设置。
