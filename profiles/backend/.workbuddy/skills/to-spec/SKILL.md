# 显式规格整理

仅用户显式调用。读取根 `CONTEXT.md`、现有需求、当前决定与相关 ADR，复用已确认成果；缺少影响行为的业务决定时澄清，不默认重做访谈。

Spec 描述可观察行为、边界、例外、非目标和验收要求；技术选择沿用实际工程或明确说明待决定事项。按本次授权保存到已有文档或用户指定位置。需要发布到 Issue tracker 时使用明确的配置与对应授权，缺配置不阻断当前草稿。

不要求生命周期入口、工程资格、批准包或阶段合同。模板源维护不创建真实业务 Spec；报告实际修改、来源、未决项及未完成动作，不自动批准或启动未授权工作。上游来源与适配信息沿既有锁文件保留。
