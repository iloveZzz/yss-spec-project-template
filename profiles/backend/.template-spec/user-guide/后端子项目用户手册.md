# 后端子项目用户手册

Backend 用于已有后端工程维护与新后端实现。向 Agent 提供当前目标、已有需求和允许修改的工程；已有资料足够时直接开展工作，不要求登记、Freeze、合同编译或阶段资格。

## 工程与 CLI

首次安装、项目接管、同步和恢复使用[统一 CLI 说明](unified-cli.md)，具体命令见[命令参考](cli/command-reference.md)。新工程参考[Backend 与脚手架](cli/tutorial-backend.md)，已有工程增量修改，不重新初始化覆盖用户文件。

先核对已安装程序的实际版本与帮助。写入按授权直接执行；`--dry-run` 只预览，不保存计划或更改目标。模板修改不自动升级本机 CLI 或已安装项目。

## 设计与实现

- 沿用实际工程的 DDD 或 MVC 架构、POM 与包结构，后端命令优先根 `./mvnw`；关键版本未知时先调查。
- DDD 的业务不变量归 Domain，事务与用例编排归 Application，Infrastructure 实现持久化和外部端口；展示分页不进入 Domain。
- MVC 的业务规则、幂等和事务归 Service，Controller 负责请求响应，Repository 负责数据访问；不强加 DDD Gateway。
- 按当前影响使用 YSS 的设计、领域、用例、持久化、Web、DTO、异常、校验与映射技能。接口与数据变化同步真实调用方，不生成平行需求或合同。
- 保留认证、权限、输入校验、SQL 参数绑定、错误脱敏和事务语义；只在授权工程中写入，不把子模块当普通目录，不覆盖用户改动。

## 交付与维护

说明实际修改、已执行命令及结果、尚未验证内容和下一动作；不把生成成功当作构建或运行成功。提交、推送、PR/MR、部署和发行使用各自动作的真实授权。

维护或中断处理参考[维护与恢复](cli/tutorial-maintenance.md)；保留未知文件和用户修改，不能通过删除事务状态或强制覆盖掩盖失败。
