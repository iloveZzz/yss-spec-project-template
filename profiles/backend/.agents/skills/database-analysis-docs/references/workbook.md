# 工作簿生成与核对

仅在用户需要 Excel 时读取。使用宿主已有的表格技能或能力，遵循其依赖发现、操作标记、导出与渲染要求；先确认实际可用能力，不假定本技能包含生成器或核对器。缺少表格能力时可完成 Markdown，明确 Excel 未完成，不编造下载入口。

## 内容与格式

从同一份已核对模型生成目录和逐表说明，用户提供模板时先核对适用性。目录包含完整 schema／表名、来源、状态、确认／建议／待定、关系和未覆盖对象；逐表说明包含字段、类型、可空性、默认值、主键、唯一键、索引、外键、SQL／业务条件及来源。

页签可以合法化并截短，但页内保留完整表名与稳定 ID，同名表不能混淆。默认值、SQL 片段、标识符、来源和长整数 ID 按文本保留，不能因以 `=` 等字符开头被当成公式，也不能因数值精度或自动日期转换丢失内容。仅明确需要的导航或统计使用工具构造的公式。日期系统、转义和表格尺寸遵循所用工具，读回时核对，不假定所有工具一致。

## 实际文件核对

1. 生成前检查模型结构、引用和来源；结构一致不证明业务充分性。
2. 写入新文件或明确获授权的目标，保护旧版本。导出失败或路径不存在时不能交付成功。
3. 使用可用的独立读取能力检查实际保存的 XLSX，核对表集合、字段、默认值、键／索引、逻辑关系、未覆盖项、日期、链接及重要文字；不能只看生成日志或 manifest。没有独立读取能力则说明未完成该项核对。
4. 按宿主能力渲染并查看实际页面，确认长中文、完整表名、默认值和来源没有裁切；未能渲染则明确视觉未验证。局部改动检查受影响页和依赖，不声称全量检查。

只报告实际运行的检查。文件一致性、视觉检查不证明 Excel／WPS 原生客户端行为或数据库执行正确。预览与检查记录通常作为核对依据，不默认成为正式交付；最终提供实际文件链接和限制。

参考：[微软工作表命名](https://support.microsoft.com/en-gb/excel/rename-a-worksheet)。用户模板或实际工具有不同限制时先核实，不静默丢字段或截断定义。
