# Plan（战略规划）

Plan 为 Spec 提供已确认的战略输入。目标和退出条件引用 [生命周期注册表](../process/lifecycle-registry.yaml)，裁剪引用 [影响面规则](../process/harness-process-tailoring.md)。

从 [规划模板](templates/plan-template.md) 开始。先识别哪些结论仍有效、哪些问题需要探索，再确认目标、业务边界、关键规则、MVP / 非目标、优先级和交接责任。业务边界与规则设计、方案决策包保留各自权威正文，Plan 通过引用组织输入，不重复定义。

问题探索是阶段内部按需开展的活动；市场和竞品事实使用 `competitive-intelligence`，技术或战略证据使用 `yss-research`。机会构想与事实核查可以反复迭代，关键问题解决后才申请进入 Spec。

历史资产处理见 [迁移说明](../process/plan-migration.md)。
