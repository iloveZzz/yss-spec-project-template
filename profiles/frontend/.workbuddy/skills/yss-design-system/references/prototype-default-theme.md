# 高保真原型默认主题

用于 Vue 3 + shadcn-vue 产品页面；低保真草稿与完善版共用组件和场景，仅简化视觉装饰。颜色、字体、尺寸仍以当前项目根 DESIGN.md 为准；主题只选择已定义的角色和组件变体。既有批准原型不自动迁移，局部修改先登记保持项。

## 密度与视觉角色

新页面默认标准亮色：控件采用 `components.button-default.height`（32px），容器采用 `components.card-compact.padding`（16px）。显式 `data-density="compact"` 使用 28px 控件；`comfortable` 使用 32px 控件和 20px Card 内边距。小于 720px 或粗指针时常用控件优先 44px，并让筛选、动作换行。表格按任务选择局部滚动或显式 `.responsive-list` 摘要，不能给所有表格强制转卡片。密度不压缩正文、焦点或错误说明，不把生产 compact algorithm 的排版结果直接套给原型，也不再次运行算法。

正文使用 `typography.body`，页面标题和分区标题分别使用 `heading-lg`、`heading-md`，辅助信息才用 `caption`。页面、内容、浮层分别使用对应表面角色；主操作使用 button-primary 系列，不能回退到品牌 seed。筛选、列表、表单和审批优先用边界与分组表达层次。

`variables.css` 中 `--yss-colors-*`、`--yss-typography-*`、`--yss-components-*` 是规范角色投影；既有 `--brand-*` 保留运行时桥接。兼容别名引用规范角色，不手工维护第二套值。修改 DESIGN 或 Token 后，同步本次采用的直接映射；只有项目工具真实支持时才调用派生。当前亮色摘要只登记已同步文件，不将旧暗色/compact 算法结果冒充当前基线。新主题的计算样式须与当前根规范比对，历史缺少角色别名的快照不作为当前规范一致性的证据。

## 默认页面结构

相应 YSS 原型合同的多页面企业任务可采用根规范 workspace 应用壳：模块、分组侧栏、页签和流式任务区。标题使用 workspace-title；既有页面保持项不被新框架覆盖。原型技能可用时参考其工作区状态；否则记录未验证的多页行为，不把页签缓存视为持久保存。

- 查询：条件与筛选动作对齐；列表标题、排序/选择状态位于紧凑工具栏，分页在结果后。窄屏按任务保留局部表格滚动，或转为带身份、名称、状态和操作的摘要列表。
- 表单：按任务分组，控制阅读宽度；错误靠近字段且可定位，返回保留输入，确认动作保持可见。
- 审批：身份、状态、责任人与操作沿行组织；不可操作原因保留可读文本，失败项保持可重试。
- 分析：指标主次与明细共用筛选；横向滚动限定在数据区域，提供提示、固定关键列与键盘访问。

页签、组合筛选、日期、视图切换和看板的具体组合见 [标准页面模式](standard-theme-patterns.md)。表头 48px 与数据行 36px 分开映射，禁止给全部单元格套用同一高度。

## 交互与检查

统一 hover、active、focus-visible、disabled、selected、invalid；反馈采用语义表面和文字。输入类控件聚焦仅使用 1px 主色边框，`--yss-focus-ring` 保留为 `none` 兼容别名，不叠加光晕或粗外轮廓；InputGroup 仅在外容器显示一次，错误边框仍保留。强制颜色模式恢复系统色焦点轮廓。动效只用于反馈且使用项目动效 Token，减少动效时取消。完整行为仍消费交互说明与状态矩阵，不由主题定义。

弹出选项不使用通用控件粗外框：Select 的选中态使用蓝字、500 字重与勾选，Hover / 当前项使用灰底，Select / Combobox / DropdownMenu 的键盘当前项使用左侧细指示线；强制颜色模式保留系统色内轮廓。核对焦点移动与选中值分别表达，Enter 确认、Escape 关闭和焦点返回仍可用。

用实际 shadcn-vue 组件、Lucide SVG 与完整基础样式核验主题；原生控件替身不能证明组件边框、图标和焦点一致。按钮明确重置原生 appearance / outset 边框，轮廓按钮保留实线边框；输入与下拉图标核对实际尺寸、颜色和对齐。按当前风险检查当前计算样式、文字对比度、选中/错误状态、桌面和窄屏、键盘与焦点返回、200% 缩放、减少动效及 console。密度变小不能作为质量提升的证据；同时检查每屏信息量、主操作可发现性与恢复任务可完成性。前后对照必须采用相同内容、状态和视口，视觉取舍复用用户已有决定。
