# 业务逻辑与状态原型

用于“规则这样组合会怎样”“撤回后能否再提交”等有边界的业务问题。先说明问题、已知规则、代表输入和判定标准，再按 [逻辑原型](LOGIC.md) 制作可操作试验，界面只帮助理解动作和状态。

默认内存状态和模拟数据，不连接真实服务。核心场景提供重置与可重复操作；缺失业务决定先澄清，不凭实验代码创造规则。操作未执行时明确未验证，不将推演写成实测。

有 UI 的完整产品需求仍需产品 UI 原型，本技能只能辅助，不能用按钮状态台代替页面设计。无 UI 的完整需求可以由业务逻辑或状态原型承担原型交付，并附规则、状态、操作说明与实际检查。

结果回到当前 Spec：问题的答案、规则或验收变化、模拟边界与未解决项。实验代码仅作候选参考，生产复用由研发重新设计和验证；不自动合入生产、创建分支、提交或发布。
