# 设计与原型复核

消费当前规格、验收和真实产物，按 [共同复核方法](references/review-method.md) 检查。仅检查实际请求和声明范围，不因技能名称要求独立评审、固定矩阵、OpenAPI 或批准流程。

制作方可读取同一方法自检；自检不能称为独立来源。组件、表单、弹窗或多页工作区命中时，补充 [组件行为检查](references/component-qa.md)，不把组件原语能力当作完整页面已通过。

发现绑定页面、状态、规则或验收位置，写明影响、依据和必要修正。行为缺陷、规范差异与偏好建议分开；未实际操作的交互明确未验证。规则冲突返回业务分析或澄清，产物修正由制作方完成。

返回检查范围、实际方式、发现和局限；关键问题修正后检查受影响部分。不重新设计产品、不伪造用户研究，也不批准业务、冻结规格或授予实施资格。
