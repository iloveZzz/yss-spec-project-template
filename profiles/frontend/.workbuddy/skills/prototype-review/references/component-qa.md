# 组件与复杂页面的条件检查

只检查实际使用的组件和承诺行为。低保真以任务、信息、入口/出口、选择范围与恢复语义为主；高保真再检查当前视觉基线和交互，不要求先确定生产组件。

| 命中范围 | 需要观察的行为 |
|---|---|
| 列表/筛选/选择 | 筛选与分页一致，跨页选择含义明确，空/失败有下一步，重置回到已知状态 |
| 表单边框与焦点 | 点击、Tab 聚焦和 Select 展开/关闭后，核对实际 border/outline/shadow 和全局 Token；错误+聚焦保留错误提示，InputGroup 只由外层绘制边框/焦点，Portal 不丢失主题 |
| 表单与保存 | 标签、帮助、错误相互关联；首错可定位；取消不改正式值；失败保留输入，重试范围明确，部分成功可理解 |
| 弹窗/侧栏/菜单 | 标题和说明完整；初始焦点、Tab、Escape、关闭后的焦点去向正确；禁用动作不能执行 |
| 搜索/日期 | 搜索词不冒充已选 ID；同名对象可区分；中文组合输入不误提交；未完整或逆序范围不可应用，清空与应用分开 |
| 多页工作区 | 导航与内容一致；草稿离开有明确处理；返回保留承诺状态；页签关闭/回退可解释，全量重置不留残态 |
| 页面与浮层 | 长中文与错误文本可读；主要动作在适用窄屏/缩放下可达；表格可局部滚动；浮层不遮蔽关键焦点 |

键盘检查按真实模式使用 Tab、方向键、Enter、Space、Escape；页面标签与内容页签不可混淆。控件名称、语义和错误关联可被辅助技术理解；视觉对比和命中区域按当前人群/设备风险核查。若触发器已消失，关闭后应有合理的后续焦点。

产品 UI 的草稿、完善版及评审工具使用真实 shadcn 控件，核对源码与版本；结构标签、组件内部 DOM 和隐藏输入允许存在，不能按渲染后 DOM 中出现 input/button 就判违规。页面切换后不得遗留 Teleport 浮层或隐藏焦点。包内示例、默认控件尺寸和构建成功都不证明实际交互或无障碍通过。

离线交付只有在本次承诺时才断网复验；按需要选取浏览器和视口，不强制全平台或固定六轴。结果写入当前交付说明，区分通过、失败、未执行与有理由的不适用，不要求独立批准文件。

发现点击或展开黑边时，先实际复现并定位产生边线的元素与计算样式；在共享主题适配层修复已证实的根因，不改固定 vendor、不全局移除 outline/border。未复现时记录浏览器、样本和状态范围，不宣称用户的问题已经修好。
