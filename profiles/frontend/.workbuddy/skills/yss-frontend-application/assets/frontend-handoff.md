- 已有工程新增行为的保留或调整，以及有依据的设计冲突处理；无冲突则省略。

## 运行与检查

- 安装、启动、检查、构建：只填目标工程实际可用的命令。
- 已执行：当前版本、命令或动作、结果和证据位置。
- 视觉：同条件来源画面与实现画面的对应、相关弹层及布局尺寸、差异与处理；旧工程快照的适用范围。
- 交互：实际操作的核心路径、相关失败/恢复和键盘焦点结果。
- Review：发现、修复、针对最终文件的复核；没有独立 review 时写自审。
- 未执行 / 剩余风险：与完成结论直接相关的限制。
