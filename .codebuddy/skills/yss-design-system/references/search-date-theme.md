# 搜索选择、日期范围与重排

本配方消费根 DESIGN 与现有 Token，不新增颜色或生命周期门禁。原型语义和规则由 `yss-prototype-stage/references/search-date-patterns.md` 持有。

| 表面 | 当前角色与检查 |
|---|---|
| 搜索输入/列表 | 使用当前密度控件、输入边框、主次文字、浮层表面；长中文允许换行，编号保持可辨；选中反馈与搜索文字分开 |
| 错误/加载/禁用 | 复用错误文字、持续反馈和禁用角色；解释原因，不仅变色或降低透明度 |
| 日期范围 | 端点用高对比主操作颜色，区间用浅主色与正文；同日仍可辨，键盘焦点独立于选中状态 |
| 日历/浮层 | 七列均分且点击区域实测；内容限制在视口与可用高度，内部可滚动；应用/取消可达，定位错误不被覆盖 |
| 窄屏 | 控件与筛选堆叠；日期输入单列；长标签、分页、主操作可重排；仅必要二维表格允许自身横向滚动 |

compact/comfortable 分别核对实际计算样式；控件高度不等于点击区域，检查至少 24 CSS px 的实际目标或满足标准的间距例外，并记录依据。增加像素值前先确认是否已有 Token；确需稳定新角色时先登记根 `DESIGN.md`，再用既有工具生成派生值，禁止手改投影。

320 CSS px 等效重排与实际 200% 浏览器缩放分别留证。重排检查筛选、分页、日期浮层、主操作和错误定位；二维数据表例外不能扩展至外围控件。按 [W3C Reflow](https://www.w3.org/WAI/WCAG22/Understanding/reflow.html) 记录不适用依据；像素截图或自动扫描不自动证明 WCAG 符合性。

焦点关闭时先检查原触发器仍存在且可见；触发器被隐藏/移除时转向当前页面主区域或明确后继，不能回到隐藏 KeepAlive 页面。键盘检查焦点环、自动滚动、固定栏遮挡、操作结果；减少动效独立核验。

目标人群使用读屏，或动态错误、复合输入、范围选择、焦点恢复有高风险时，追加人工读屏：记录 OS、浏览器、辅助技术及版本；依次听取名称/角色/值、同名 ID、加载/失败、选中反馈、日期端点、应用/取消和离页后焦点。环境缺失写“未执行”及受影响结论；不能把自动扫描写成读屏通过。边界参考 [Playwright accessibility testing](https://playwright.dev/docs/accessibility-testing)。
