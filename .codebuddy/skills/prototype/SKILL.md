# 逻辑与状态试验

先写明问题、代表性输入和判定标准，再按 [LOGIC.md](LOGIC.md) 构建可运行的独立试验。默认内存状态，界面仅展示动作与状态，不探索产品视觉方案。

正式产品 UI 原型回到当前生命周期的产品设计阶段，由已安装的产品原型阶段技能持有合同；后端 profile 不因此安装前端技能。

试验资产放在获准的本地路径，明确标注 throwaway，保存输入、实际结果和局限，回交当前设计负责人。不得直接转为生产代码、批准合同、推进门禁或宣称发布；提交、推送和 tracker 发布仍需要各自授权。
