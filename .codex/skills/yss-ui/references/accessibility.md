# YSS UI 可访问性、响应式与性能

## 可访问性

- 图标按钮必须有可访问名称或可见文本。
- 表单 label、错误提示和输入控件建立语义关联。
- 状态不能只用颜色表达；同时提供文本或图标语义。
- Tab 顺序符合视觉与业务顺序；主要动作支持键盘触发。
- Modal/Drawer 处理焦点进入、捕获、关闭恢复和 Escape 行为。
- 对比度目标以项目测试策略为准；不足时修复主题 token，不制造页面特例。

## 响应式

- 明确目标断点和窄屏降级，不默认所有后台页面只运行在大屏。
- Table 在窄屏提供横向滚动、列优先级或操作菜单收敛。
- 主从布局在宽度不足时切换 Drawer、上下布局或独立页面。

## 性能

- 大数据 Table/Tree 使用项目已验证的虚拟化能力。
- 远程 Select、Tree 搜索使用防抖、取消过期请求和 loading/empty/error 状态。
- Monaco、ECharts、复杂 Formily 和大组件按需加载。
- 禁止在 Vue 模板中执行排序、深拷贝或高成本结构转换。
