# 原生模板运行时替代实施 Spec

状态：已由用户于 2026-08-17 确认范围与实施授权。

## 问题

当前 `create-yss-spec` 与模板实例公开治理操作依赖 Node。目标是以 Rust 3.0 提供等价的用户侧 CLI 与实例运行时，保留维护侧 Node，并以 RC 后稳定发布形成替代结论。

## 验收基线

- 全部公开 CLI 与实例运行时行为以 Node 2.x 的固定 fixture 黑盒输出为 oracle；
- 用户侧无 Node 前置条件；
- 目标平台、签名、安装、N-1 回滚、跨仓与性能要求以 ADR-0011 和发布合同为准；
- 未通过 RC 全部阻断项前不得声称替代或切换 npm `latest`。

## 非功能范围

无 OpenAPI、UI、数据库、前后端运行时代码或权限业务变化。
