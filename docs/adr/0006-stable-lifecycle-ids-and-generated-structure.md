# ADR-0006: 使用稳定命名空间 ID 并派生生命周期结构资产

> 状态：部分实施（Phase 1）。稳定 ID、发布基线和两份结构视图已受管；索引、依赖图和测试 fixture 的完整生成属于后续提案，未实现前不得把人工维护的场景断言称为派生产物。

生命周期对象的中文名称、展示顺序和数量会随流程演进而变化，不能继续用“第几个门禁”或表格行数作为兼容身份。Phase 1 为主阶段、门禁、产物、工作单元和证据分别使用 `stage.*`、`gate.*`、`artifact.*`、`work-unit.*`、`evidence.*` 稳定 ID，并由 `docs/process/lifecycle-registry.yaml` 生成当前结构表；用户指南、ADR 和实践说明继续人工维护并引用稳定 ID。数量、索引、依赖图和测试 fixture 必须在后续 Phase 通过同一生成器和 `--check` 一并交付。已发布 ID 不复用，语义变化通过弃用记录和 schema 迁移表达，以牺牲直接编辑派生表格的便利换取跨版本引用稳定性。
